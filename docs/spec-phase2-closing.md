# 第2弾（3）決算整理・年度繰越 仕様

「その他」→「決算・繰越」（`#/closing`）と「会計期間」（`#/periods`）。
IndexedDB のスキーマ・バックアップ形式は変えない（periods ストアに期間が増えるだけ）。

## 1. 期末の棚卸（三分法の決算整理仕訳）
- 期末の棚卸高を入力すると、期末日の日付で1つの仕訳を登録する
  - 期首商品棚卸高 ／ 商品（決算整理前の商品の残高＝期首の在庫）
  - 商品 ／ 期末商品棚卸高（期末の在庫）
- 科目は役割（期首・期末商品棚卸高）と目印 `inventory`（商品）で探す。既存データには起動時に目印を補う
- 期首・期末の棚卸高の科目を使った仕訳が既にあれば、登録済みとして表示する（二重登録を防ぐ）

## 2. そのほかの決算整理
- 減価償却・未払/前払・法人税等・家事按分などは、振替伝票で入力するよう案内する（固定資産の機能は今後）

## 3. 年度繰越
- 次の期間の日付：個人は翌年の1/1〜12/31。法人は前期末の翌日から12か月
- 期首残高：貸借の科目の期末残高を補助科目ごとに繰り越す。損益の科目は繰り越さない
  - 法人：繰越利益剰余金に当期純利益を加える
  - 個人：事業主貸・事業主借は0。元入金は「期首の資産合計−負債合計」で計算する
    （＝前期の元入金＋青色申告特別控除前の所得金額＋事業主借−事業主貸）
    - 根拠：国税庁「令和7年分 青色申告決算書（一般用）の書き方」6ページ。元入金は「期首の金額と期末の金額は同じ金額を記入」、
      事業主貸・事業主借は「本年中に」支出・受け入れた金額の合計
      https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/037.pdf
- 繰越前にプレビュー（次の期間の期首残高）を表示し、確認してから作成する。作成と同時に表示中の期間を切り替える
- 重なる期間は作れない（Repository とバックアップの検証の両方で確認）。法人の期首残高は貸借一致を再検証する

## 4. 会計期間の切替と前期の修正
- 「会計期間」で表示する期間を切り替えられる。過去の期間を表示中はホームに注意を出す
- 繰越の後に前期の仕訳を直すと、次の期間の期首残高が前期末と合わなくなる。これを検出して注意を出し、
  「前期末の残高で期首残高を更新」で再計算できる（期首残高を利用者が手で変えた場合も同じ扱い）

## 5. 締め（たかとさんの判断：必須）
- 「会計期間」で、次の期間へ繰り越した後の期間を「締める」ことができる
- 締めた期間は、仕訳の追加・編集・削除・削除の取り消し、期首残高、期間の日付を変更できない（Repository で拒否。画面は表示のみ）
  - 締めた期間の仕訳を別の期間へ移す変更も拒否する
- 「締めを解除」で元に戻せる（確認つき）。解除して前期を直したら、次の期間の期首残高を更新してから締め直す
- 期間レコードに `closed`（真偽）と `closedAt` を持たせる（スキーマ・バックアップ形式の変更なし）
