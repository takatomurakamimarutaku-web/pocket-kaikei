# 第2弾（4）固定資産・減価償却 仕様

固定資産台帳に資産を登録すると、年ごとの減価償却費を計算し、決算・繰越の画面から決算整理の仕訳を登録できる。

## 2. 対応する償却方法

| 方法 | 計算 | 条件（入力時に検証） |
|---|---|---|
| 定額法 | 取得価額×定額法の償却率×月数/12 | 平成19年4月1日以後に使い始めたもの。耐用年数2〜50年 |
| 定率法（200%） | 期首帳簿価額×償却率。調整前償却額＜取得価額×保証率 になった年から 改定取得価額×改定償却率 | 平成24年4月1日以後の取得。建物・無形は不可、建物附属設備・構築物は平成28年4月1日以後の取得は不可 |
| 一括償却資産 | 取得価額×期間の月数/36（12か月の期間なら1/3）。月の途中から使っても按分しない | 取得価額20万円未満 |
| 少額減価償却資産 | 使い始めた期間に全額 | 取得価額10万円未満 |
| 少額減価償却資産の特例 | 使い始めた期間に全額 | 令和8年3月31日までの取得は30万円未満、4月1日以後は40万円未満。平成18年4月1日〜令和11年3月31日の取得。期間の合計が300万円（1年未満の期間は月数で按分）を超えると注意を表示 |

- 有形固定資産の定額法・定率法は1円を残す（備忘価額）。無形固定資産は0円まで償却する
- 1円未満は切り捨て。最後の年は残り（−1円）までにする
- 除却・売却した日を入れると、その月までの月数で償却し、以後は償却しない（一括償却資産は除却後も3年間償却を続ける）
- 個人は「事業で使う割合」を入れる。償却費のうち割合分が経費（減価償却費）、残りは事業主貸
- 取得価額は税込経理なので消費税込みで入力し、10万円・20万円などの判定も税込（No.2100）
- 届出をしていない場合の方法（法定償却方法）の案内：個人は定額法、法人の機械・車両・器具備品は定率法

## 3. 期間の扱い

- 登録済みの会計期間はそのまま使う（法人の1年未満の最初の期間も、月数で按分）
- アプリを使う前の年分・まだ作っていない先の年分は、会計期間の開始日に合わせた12か月の期間で補って計算する

## 4. 仕訳

決算・繰越の画面「2. 減価償却」から、期末日の日付で1件の仕訳を登録する（仕訳に `source: 'depreciation'` を付けて登録済みかを判定）。

| | 借方 | 貸方 |
|---|---|---|
| 個人 | 減価償却費（事業分）・事業主貸（私用分） | 資産の科目（直接法） |
| 法人・有形固定資産 | 減価償却費 | 減価償却累計額（科目が有効なとき。無ければ直接法） |
| 法人・無形固定資産 | 減価償却費 | 資産の科目（直接法） |

科目は目印（`hint`）の `depreciation`・`accumulated_depreciation` で選ぶ（既存データには起動時にテンプレートのコードで補う）。
登録後に台帳を直して金額が変わったときは、決算画面に差額の注意を出す。

## 5. データ

- IndexedDB：`assets` ストアを追加（`DB_VERSION` 2、`accountId` インデックス）。固定資産で使っている科目は削除できない
- バックアップ：`assets` を追加（`BACKUP_VERSION` 2。バージョン1のファイルは `assets: []` として読み込む）
- 資産のレコード：`id, name, category, accountId, acquiredOn, startedOn, cost, method, usefulLife, businessRatio, disposedOn, memo, createdAt, updatedAt`
