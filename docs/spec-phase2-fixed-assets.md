# 第2弾（4）固定資産・減価償却 仕様

固定資産台帳に資産を登録すると、年ごとの減価償却費を計算し、決算・繰越の画面から決算整理の仕訳を登録できる。

## 2. 対応する償却方法

| 方法 | 計算 | 条件（入力時に検証） |
|---|---|---|
| 定額法 | 取得価額×定額法の償却率×月数/12 | 平成19年4月1日以後に使い始めたもの。耐用年数2〜50年 |
| 定率法（200%） | 期首帳簿価額×償却率。調整前償却額＜取得価額×保証率 になった年から 改定取得価額×改定償却率 | 平成24年4月1日以後の取得。建物・無形は不可、建物附属設備・構築物は平成28年4月1日以後の取得は不可 |
| 一括償却資産 | 取得価額×期間の月数/36（12か月の期間なら1/3）。月の途中から使っても按分しない | 取得価額20万円未満 |
| 少額減価償却資産 | 使い始めた期間に全額 | 取得価額10万円未満 |
| 少額減価償却資産の特例 | 使い始めた期間に全額 | 令和8年3月31日までの取得は30万円未満、4月1日以後は40万円未満。平成18年4月1日〜令和11年3月31日の取得。期間の合計が300万円（1年未満の期間は月数で按分）を超えると注意を表示 |

- 有形固定資産の定額法・定率法は1円を残す（備忘価額）。無形固定資産は0円まで償却する
- 1円未満は切り捨て。最後の年は残り（−1円）までにする
- 除却・売却した日を入れると、その月までの月数で償却し、以後は償却しない（一括償却資産は除却後も3年間償却を続ける）
- 個人は「事業で使う割合」を入れる。償却費のうち割合分が経費（減価償却費）、残りは事業主貸
- 取得価額は税込経理なので消費税込みで入力し、10万円・20万円などの判定も税込（No.2100）
- 届出をしていない場合の方法（法定償却方法）の案内：個人は定額法、法人の機械・車両・器具備品は定率法

## 3. 期間の扱い

- 登録済みの会計期間はそのまま使う（法人の1年未満の最初の期間も、月数で按分）
- アプリを使う前の年分・まだ作っていない先の年分は、会計期間の開始日に合わせた12か月の期間で補って計算する

## 4. 仕訳

決算・繰越の画面「2. 減価償却」から、期末日の日付で1件の仕訳を登録する（仕訳に `source: 'depreciation'` を付けて登録済みかを判定）。

| | 借方 | 貸方 |
|---|---|---|
| 個人 | 減価償却費（事業分）・事業主貸（私用分） | 資産の科目（直接法） |
| 法人・有形固定資産 | 減価償却費 | 減価償却累計額（科目が有効なとき。無ければ直接法） |
| 法人・無形固定資産 | 減価償却費 | 資産の科目（直接法） |

科目は目印（`hint`）の `depreciation`・`accumulated_depreciation` で選ぶ（既存データには起動時にテンプレートのコードで補う）。
登録後に台帳を直して金額が変わったときは、決算画面に差額の注意を出す。

## 5. データ

- IndexedDB：`assets` ストアを追加（`DB_VERSION` 2、`accountId` インデックス）。固定資産で使っている科目は削除できない
- バックアップ：`assets` を追加（`BACKUP_VERSION` 2。バージョン1のファイルは `assets: []` として読み込む）
- 資産のレコード：`id, name, category, accountId, acquiredOn, startedOn, cost, method, usefulLife, businessRatio, disposedOn, memo, createdAt, updatedAt`

## 6. 前の帳簿からの引き継ぎ（v0.10.0）

アプリを使う前から持っている定額法・定率法の資産は、アプリで最初の会計期間の期首の帳簿価額（前の会計ソフトや前年の青色申告決算書の「未償却残高」）を入力できる。

- 入力欄は、使い始めた日がアプリで最初の会計期間より前のときだけ出る。空欄なら従来どおり使い始めた日から計算した額を使う
- 引き継いだ日（`carryOn`＝最初の会計期間の期首）より前の年分は計算に出さず、その日の帳簿価額（`carryBook`）から償却を続ける
  - 定額法：取得価額×償却率×月数/12（帳簿価額ではなく取得価額で計算するため、引き継いでも毎年の額は変わらない。最後は1円まで）
  - 定率法：期首帳簿価額×償却率。前の帳簿で改定償却率に切り替え済みなら改定取得価額（`carryRevisedBase`）を入力する。空欄なら、引き継いだ年に償却保証額を下回ったときはその年の期首帳簿価額を改定取得価額にする
- 検証：引き継ぐ日は使い始めた日より後、除却日以前。帳簿価額は有形1円・無形0円以上で取得価額以下。改定取得価額は定率法だけ
- データ：資産のレコードに `carryOn`・`carryBook`・`carryRevisedBase`（いずれも任意、既定 null）を追加。ストアは変えず、古いバックアップ（項目なし）もそのまま読めるので `DB_VERSION`・`BACKUP_VERSION` は上げない

### 売却・除却の仕訳（`js/asset-tools.js` の `disposalLines`）

帳簿価額は、売却・除却した月までの償却費を引いた額（その年の償却費は従来どおり決算の画面で期末日に登録する）。

| 場合 | 仕訳 |
|---|---|
| 法人・有形固定資産（減価償却累計額の科目あり） | まず 減価償却累計額 / 資産（取得価額−帳簿価額） |
| 売却 | 入金先 / 資産（売却額、課税売上10%）。売却額＞帳簿価額なら 資産 / 固定資産売却益、＜なら 固定資産売却損 / 資産 |
| 売却（個人） | 差額は譲渡所得なので、売却益は事業主借、売却損は事業主貸。私用にも使っていた資産は売却額のうち事業割合の分だけ課税売上、残りは対象外 |
| 除却 | 固定資産除却損 / 資産（帳簿価額）。個人は事業割合の分を選んだ経費の科目（初期値は雑費）、残りを事業主貸 |

- 定額法・定率法の資産だけ（一括償却資産は除却後も3年で償却を続け、少額の資産は取得時に全額を費用にしているため対象外）
- 科目は目印で選ぶ：法人のテンプレートの固定資産売却益・売却損・除却損に `asset_sale_gain`・`asset_sale_loss`・`asset_retirement_loss`、雑費に `misc_expense` を追加（既存データにも起動時にテンプレートのコードで補う）
- 根拠：事業用固定資産の売却は消費税の課税対象（国税庁 質疑応答「事業者の事業用固定資産の売却」）、個人の機械・車両などの売却は譲渡所得（No.3105）、業務用資産の除却損は必要経費（No.2210）

### データ

- 資産のレコードに `assetNo`・`quantity`・`location`・`disposalType`（sell／retire）・`salePrice` を追加（いずれも任意、古いデータには無くてよい）
- 売却・除却の仕訳は `source: 'asset_disposal'`、`sourceId`：資産の id
- ストアとバックアップの形式は変えていないので `DB_VERSION`・`BACKUP_VERSION` は上げない

## 9. 旧定額法・旧定率法・250%定率法と特別償却（v0.36.0）

### 根拠（2026-10-29 確認）
| 内容 | 出典 |
|---|---|
| 旧定額法：（取得価額−残存価額）×償却率。旧定率法：期首未償却残高×償却率。有形の残存価額は取得価額の10%（無形は0） | 国税庁 No.2105 |
| 償却費の累積額が取得価額の95%に達した年の翌年から5年間、{(取得価額−取得価額×95%−1円)÷5}×本年中の償却期間/12 で1円まで均等に償却。摘要に「均等償却」 | No.2105、「令和7年分 青色申告決算書（一般用）の書き方」 |
| 平成19年3月31日以前に取得し、4月1日以後に事業の用に供した資産は、供用日に取得したとみなす | No.5410 |
| 旧定額法・旧定率法（別表第七）・250%定率法（別表第九）の償却率・改定償却率・保証率 | 青色申告決算書の書き方 037.pdf の償却率等表と、「個人の減価償却制度の改正について」資料編（070412/pdf/3.pdf）の2つで照合 |
| 特別償却限度額：中小企業投資促進税制は基準取得価額の30%（事業供用年度）、中小企業経営強化税制は取得価額−普通償却限度額（即時償却） | No.5433・No.5434 |
| 青色申告決算書の「割増（特別）償却費」は普通償却費を含めずに書き、摘要に特例名を書く | 青色申告決算書の書き方 |

URL はコード（`js/depreciation.js`）の先頭に記載。

### 方法の選び方（`methodVariant()`）
入力する方法は今までどおり「定額法」「定率法」。使い始めた日・取得日で計算の区分を決める。

| 区分 | 条件 | 表示 |
|---|---|---|
| 旧定額法・旧定率法 | 使い始めた日が平成19年3月31日以前 | 旧定額法・旧定率法 |
| 250%定率法 | 取得日（みなし取得日）が平成19年4月1日〜平成24年3月31日 | 定率法（入力画面に「250%定率法」と率） |
| 200%定率法 | 取得日が平成24年4月1日以後 | 定率法 |

- 建物（平成10年4月以後の取得）・建物附属設備と構築物（平成28年4月以後の取得）は定率法を選べない決まりはそのまま
- 平成24年4月1日をまたぐ事業年度の経過措置（その年度中に取得した資産に250%定率法を使える特例など）には対応しない

### 計算（`depreciationSchedule()`）
| 区分 | 1年分の償却費 | 終わり |
|---|---|---|
| 旧定額法（有形） | 取得価額×90%×償却率 | 累積額が取得価額の95%（帳簿価額が取得価額×5%）まで。翌年から均等償却 |
| 旧定額法（無形） | 取得価額×償却率 | 0円まで |
| 旧定率法 | 期首帳簿価額×償却率 | 95%まで。翌年から均等償却 |
| 均等償却 | （取得価額×5%−1円）×月数/60 | 5年で1円。5年で終わるよう1円未満は切り上げる（No.2105 の計算例：50,000円×4年＋49,999円） |
| 250%定率法 | 200%定率法と同じ計算で、別表第九の率 | 1円 |

- 1円未満は今までどおり切り捨て（No.5410 の計算例と同じ）。No.2105 の旧定率法の計算例は1円未満を切り上げているため、途中の年が数円違う（例：500万円・5年の7年目は国税庁 65,606円、このアプリ 65,608円。合計と均等償却の額は同じ）
- 前の帳簿からの引き継ぎ（6章）は旧定額法・旧定率法でも使える。帳簿価額が取得価額×5%以下なら均等償却から続ける

### 特別償却
- 資産に「特別償却の率（%）」と「制度の名前」を入れる（`specialRate`・`specialName`。任意）。100% は即時償却
- 使い始めた日を含む期間に、普通償却費に加えて 取得価額×率 を償却する（月数按分しない）。即時償却は 取得価額−普通償却費。有形は1円を残す
- 翌年からは普通償却を続ける（定額法は取得価額×償却率で1円まで、定率法は小さくなった帳簿価額×償却率）
- 個人の事業で使う割合は、普通償却と特別償却の合計にかける
- 決算整理の仕訳は普通償却と合わせて1行（減価償却費 / 資産 または減価償却累計額）。直接減額する方法で、特別償却準備金（積立金方式）は持たない
- 青色申告決算書の3ページに「割増（特別）償却費」「本年分の償却費合計」の列を足し、摘要に制度の名前を出す。固定資産台帳の CSV に「うち特別償却」の列を足した
- 入力できないもの（保存しない）：定額法・定率法以外、平成19年3月31日以前に使い始めた資産、前の帳簿から引き継ぐ資産（特別償却は前の帳簿で済んでいる）、制度の名前の無いもの
- 対応しないもの：割増償却、特別償却不足額の繰越し、基準取得価額が取得価額と違う制度（取得価額で計算する）、制度ごとの対象・期限・中小企業者等の要件の判定

### データ
- 資産のレコードに `specialRate`・`specialName`（任意、既定 null）を足した。ストアは変えず、古いバックアップ（項目なし）もそのまま読めるので `DB_VERSION`・`BACKUP_VERSION` は上げない（読み込みでは `validateAsset()` で検証する）
