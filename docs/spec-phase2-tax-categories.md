# 第2弾：詳しい税区分（弥生会計・freee を参考に）

税区分を 10 から 37 に増やし、売上の返品・貸倒れ・輸入・仕入の用途区分（個別対応方式）を申告計算に反映する。
既存の税区分コードはそのまま使えるので、IndexedDB のスキーマとバックアップの形式は変えていない（v0.13.0）。

## 1. 税区分

| グループ | 税区分（コード） | 金額がプラスになる側 | 計算での扱い |
|---|---|---|---|
| 対象外・非課税仕入 | 対象外（不課税）`none`、非課税仕入 `purchase_exempt` | 借方 | 使わない |
| 売上 | 課税売上10%・8%（軽減）`sales_10`・`sales_8r` | 貸方 | 課税標準額 |
| | 輸出売上（免税）`sales_export` | 貸方 | 課税売上割合の分子・分母 |
| | 非課税売上 `sales_exempt` | 貸方 | 課税売上割合の分母 |
| | 有価証券等の譲渡（非課税）`sales_securities` | 貸方 | 譲渡対価の **5%** を分母（No.6405） |
| 売上の返品・値引き・貸倒れ | 売上の返品・値引き10%・8% `sales_return_10`・`_8r` | 借方 | 返還等対価に係る税額（No.6359）。割合の分子・分母から引く |
| | 輸出売上・非課税売上の返品・値引き `sales_export_return`・`sales_exempt_return` | 借方 | 割合の分子・分母から引く |
| | 貸倒れ10%・8% `sales_baddebt_10`・`_8r` | 借方 | 貸倒れに係る税額（No.6367）。割合からは引かない |
| | 貸倒れの回収10%・8% `sales_recovered_10`・`_8r` | 貸方 | 控除過大調整税額に加算（No.6631） |
| 仕入・経費 | 課税仕入10%・8%、インボイスなし10%・8%（既存） | 借方 | 課税仕入れ等の税額（インボイスなしは経過措置の割合） |
| | 仕入の返品・値引き10%・8% `purchase_return_10`・`_8r` | 貸方 | 課税仕入れ等の税額から引く。引ききれない分は控除過大調整税額（No.6363） |
| 輸入 | 輸入の消費税（国税）`import_tax` | 借方 | **金額そのものが税額**。課税仕入れ等の税額に入れる（消費税のあらまし） |
| | 輸入の地方消費税（貨物割）`import_local` | 借方 | 記録と集計だけ（国税の計算には使わない） |
| 仕入・経費（共通対応） | 上の仕入・返品・輸入の各区分の末尾 `_c` | | 個別対応方式で課税売上割合を掛ける |
| 仕入・経費（非課税売上対応） | 同じく末尾 `_e` | | 個別対応方式では控除しない |

- 「仕入・経費」グループ（末尾なし）は **課税売上対応** として扱う。
- 共通対応・非課税売上対応のグループは、設定の「仕入の用途区分」を「使う」にしたときだけ選択肢に出る（`settings.taxUseSplit`）。保存済みの仕訳の区分は設定にかかわらず表示する。
- 既存の使い方（課税売上の借方に返品を入れる・課税仕入の貸方に返品を入れる）もそのまま使える。
- 選択肢はグループ見出し（`optgroup`）付きで、`js/ui.js` の `taxSelect()` に共通化した（振替伝票・かんたん入力・銀行明細の取り込み・振り分けルール・勘定科目の既定の税区分）。

## 2. 申告計算（`js/tax-return.js`）

```
消費税額               ＝ 課税標準額×7.8%（＋軽減×6.24%）
控除過大調整税額       ＝ 貸倒れの回収×7.8/110（軽減6.24/108）＋ 引ききれない仕入の返品の税額
控除対象仕入税額（一般）
  用途区分ごとの税額   ＝ 課税仕入×7.8/110 ＋ インボイスなし×7.8/110×経過措置 ＋ 輸入の消費税 − 仕入の返品×7.8/110
  課税売上割合95%以上かつ課税売上高5億円以下 → 全用途区分の合計（全額控除）
  それ以外・個別対応方式   → 課税売上対応 ＋ 共通対応×課税売上割合
  それ以外・一括比例配分方式 → 全用途区分の合計×課税売上割合
控除対象仕入税額（簡易・2割・3割）
  税率ごとに（消費税額＋貸倒れの回収の税額−売上の返品の税額）×みなし仕入率・80%・70%
返還等対価に係る税額   ＝ 売上の返品×7.8/110（軽減6.24/108）
貸倒れに係る税額       ＝ 貸倒れ×7.8/110（軽減6.24/108）
控除税額小計           ＝ 控除対象仕入税額＋返還等対価に係る税額＋貸倒れに係る税額
差引税額               ＝ 消費税額＋控除過大調整税額−控除税額小計（百円未満切り捨て）
課税売上割合           ＝ (課税売上の税抜−返品の税抜＋輸出−輸出の返品)
                         ÷ (分子＋非課税売上−非課税の返品＋有価証券等の譲渡×5%)
```

- 課税売上割合を掛けた結果は1円未満切り捨て（大きな金額でも誤差が出ないよう BigInt で計算）。
- 按分の方法（個別対応・一括比例）は申告計算の画面で選び、会計期間の `period.taxReturn.allocation` に保存する（省略時は一括比例配分方式）。
- 一括比例配分方式を選ぶと2年間以上続ける必要がある旨、個別対応方式で用途区分の仕訳が無い旨を注意として出す。

## 3. 確認

- `test/tax-return.test.js`
  - 国税庁の2割特例の設例（貸倒回収・貸倒処理・対価返還がある場合）と、課税標準額・消費税額 601,801円・控除過大調整税額 5,703円・特別控除税額 482,878円・返還等対価 3,906円・貸倒れ 2,405円・差引税額 118,300円・地方消費税 33,300円 がすべて一致。
  - 課税売上割合（返品は引く・貸倒れは引かない・有価証券は5%）、個別対応方式と一括比例配分方式、95%以上なら非課税売上対応も全額控除、仕入の返品が多いときの加算、簡易課税で返品を引いてからみなし仕入率。
- `test/tax.test.js`：符号（返品・貸倒れは借方プラス、仕入の返品は貸方プラス）、輸入の消費税は金額が税額、全区分にグループ・役割があること、既存コードが残っていること、集計のグループと参考の差引税額。
- スクリーンショット：`shots/corporation-46-entry-tax-detail.png`（共通対応の仕入の入力）、`-47-tax-detail.png`（集計）、`-48-tax-return-individual.png`（個別対応方式）。

## 4. 未対応

- 課税売上割合に準ずる割合、特定課税仕入れ（リバースチャージ）、課税期間が1年未満のときの5億円の年換算
- インボイスのない仕入の返品の専用区分（インボイスなしの区分の貸方に入れれば、日付の割合で減る）
- 簡易課税で複数の事業区分がある場合、簡易課税で税率の一方だけ返品が売上の税額を超える場合の細かい扱い（その税率の基礎を0にしている）
- 課税売上がまったく無い期間（総売上高0）は全額控除として計算している
- 積上げ計算、令和9年4月からの飲食料品の税率の引き下げ

## 消費税集計の帳票（v0.17.0）

弥生会計の「消費税集計表」「科目別税区分表」（年間推移・決算仕訳を含めるかの指定）、勘定奉行の科目別・税区分別の集計と税区分の確認を参考にした。
参考 https://support.yayoi-kk.co.jp/product/account/zeikubun_kamoku.html 、https://support.yayoi-kk.co.jp/product/account/shohitax_uri_total.html

消費税集計の画面（`#/reports/tax`）に表示の切り替えを足した。月の範囲と「決算整理の仕訳を含める」は共通
- 税区分別：従来の税区分別集計
- 科目別（科目別税区分集計表）：科目ごとに使った税区分の税込金額・税抜（参考）・消費税等（参考）・件数。損益の科目は「対象外」も出す（課税の経費が対象外になっていないかの確認）。最後に税区分ごとの合計（対象外を除くと税区分別集計と一致）。CSV
- 月別推移：税区分ごとの月の税込金額／消費税等（参考）と差引。CSV
- チェック（税区分のチェックリスト）：`tax-reports.js` の `taxChecks`
  - 誤りの可能性が高い（warn）：収益の科目に仕入の税区分、費用の科目に売上の税区分（返品・貸倒れの区分は除く）、現金・預金・債権債務など（固定資産・投資・繰延資産以外の貸借の科目）に税区分
  - 念のため確認（info）：仕入の税区分が費用の貸方、売上の税区分が収益の借方（返品・値引きの区分の使い忘れ）、科目の初期値と違う税区分（指定したときだけ）
