# 法人税の申告（別表）（v0.49.0）

帳簿の利益から、法人税申告書の主な別表の写しと、法人住民税・事業税を含めた「納める税額」を作る（`js/corporate-tax.js`・`#/reports/corporate-tax`、入力は `#/reports/corporate-tax/input`）。
弥生会計・freee の法人税申告ソフトと同じく、別表四で所得を出し、別表一で税額を計算し、別表五(一)で検算する流れにした。
対象は資本金1億円以下の普通法人（青色申告）。

## 1. 計算の流れ

1. 別表十五：交際費等の損金不算入額
2. 別表四：当期利益に加算・減算して所得金額を出す。欠損金の控除には別表七(一)を使う
3. 別表一：法人税、地方法人税、防衛特別法人税
4. 法人住民税（法人税割・均等割）、事業税・特別法人事業税（既存の `enterprise-tax.js`）
5. 別表五(二)：租税公課の納付状況と納税充当金
6. 別表五(一)：利益積立金額と、その検算

## 2. 税率と計算（国税庁で確認・2026-10-29）

### 法人税（No.5759。令和8年4月1日現在の法令等）

- 中小法人（期末の資本金1億円以下など）の年800万円以下の部分
  - 特例は15%。対象は平成24年4月1日から令和9年3月31日までの間に開始する事業年度（措法42の3の2。令和7年度改正で2年延長）
  - 本則は19%。適用除外事業者（前3年以内に終了した各事業年度の所得の年平均額が15億円超）も19%
  - 令和7年4月1日以後に開始する事業年度で、所得金額が年10億円を超えるときは17%
- 年800万円を超える部分と、中小法人以外の法人は23.2%
- 年800万円は事業年度の月数で月割し、1,000円未満を切り捨てる
- 出典
  - https://www.nta.go.jp/taxes/shiraberu/taxanswer/hojin/5759.htm
  - 「令和7年版 法人税のあらましと申告の手引」の税率の表：https://www.nta.go.jp/publication/pamph/hojin/aramashi2025/pdf/01-02.pdf
  - 令和7年度改正の概要：https://www.nta.go.jp/publication/pamph/hojin/kaisei_gaiyo2025/pdf/F.pdf
- 令和9年4月1日以後に開始する事業年度は、いまの法令どおり19%で計算する。今後の税制改正で延長されたら直す必要がある

### 地方法人税

- 令和元年10月1日以後に開始する課税事業年度は10.3%：https://www.nta.go.jp/publication/pamph/hojin/chihou_hojin/01.htm
- 課税標準は「所得の金額に対する法人税額」（法人税額−法人税額の特別控除額。所得税額控除の前）。1,000円未満を切り捨てる
- 税額は100円未満を切り捨てる
- 別表一の記載要領（令和8年4月1日以後終了事業年度等分）：https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hojin/shinkoku/itiran2026/pdf/01-01-ki.pdf
- 令和元年10月1日より前に開始した事業年度には対応しない（画面に注意を出す）

### 防衛特別法人税（令和7年度改正で創設）

- 令和8年4月1日以後に開始する事業年度が対象
- 課税標準法人税額＝基準法人税額−基礎控除額（年500万円。1年未満は月割）
  - 基準法人税額は、所得税額控除などを適用しないで計算した法人税額。別表一では地方法人税と同じ「所得の金額に対する法人税額」
- 税率4%
- 税額が0円でも申告が必要
- 中間申告は令和9年4月1日以後に開始する事業年度から
- 出典
  - https://www.nta.go.jp/publication/pamph/hojin/kaisei_gaiyo2025/pdf/E.pdf
  - https://www.e-tax.nta.go.jp/topics/2026/topics_20260417.htm
- 課税標準の1,000円未満と税額の100円未満の切捨ては、国税通則法 第118条・第119条によった（防衛特別法人税の資料では未確認）

### 別表十五（交際費等。No.5265）

- 中小法人の損金算入限度額は、次の多いほう
  - 接待飲食費の50%
  - 定額控除限度額：交際費等の額と「800万円×月数/12」の少ないほう
- 中小法人以外は、接待飲食費の50%だけ
- 1人あたり1万円以下の飲食費（令和6年4月1日以後に支出したもの）は交際費等に含めない。画面で案内だけする
- 出典
  - https://www.nta.go.jp/taxes/shiraberu/taxanswer/hojin/5265.htm
  - 別表十五の記載要領：https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hojin/shinkoku/itiran2025/pdf/r01-15.pdf
- 交際費の額は、既定では「接待交際費」の科目の当期の額
  - 科目は目印 `entertainment` で探す。テンプレートのコード608に追加し、既存のデータには起動時の `fillHints` で付く
  - 入力すれば、その額で計算する

### 別表四（簡易様式の行に合わせる）

- 加算
  - 損金経理をした法人税及び地方法人税（防衛特別法人税を含む）
  - 損金経理をした道府県民税及び市町村民税
  - 損金経理をした納税充当金：当期に未払法人税等（目印 `income_taxes_payable`）の貸方に入れた額
  - 交際費等の損金不算入額
  - その他（入力）
- 減算
  - 納税充当金から支出した事業税等の金額：前期分の事業税・特別法人事業税
  - その他（入力）
- 仮計、法人税額から控除される所得税額（社外流出）、合計、欠損金の当期控除額（※）、所得金額
- 留保②と社外流出③を分けて持ち、総額＝留保＋社外流出になる（テストで確認）
- 様式：https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hojin/shinkoku/itiran2025/pdf/04-k.pdf
- 行の番号は様式の年度で変わるため出さない。行の名前だけ様式に合わせる
- 中間納付の税は、損金経理（法人税等の科目で処理）した前提にする。仮払経理には対応しない

### 別表七(一)（欠損金）

- 控除限度額は、中小法人等は所得の100%、それ以外は50%
- 古い事業年度の欠損金から控除する
- 繰越期間は、平成30年4月1日以後に開始した事業年度の欠損金が10年、それより前が9年
- 入力は事業年度の終了日だけなので、事業年度は12か月とみなして開始日を出す（推測による簡略化）
- 当期が欠損なら、翌期に繰り越す行を足す

### 別表五(一)・五(二)

- 前期分の確定税額は、当期に納税充当金（未払法人税等）を取り崩して納めた前提にする（入力）
- 中間分は損金経理で納めた前提にする（入力。事業税は事業税の画面の中間納付額を使う）
- 納税充当金の取崩額で、帳簿の借方の額と前期分の入力が違えば、その差を「その他」とし、注意を出す
- 別表五(一)の行
  - 純資産の科目：利益準備金など。資本金・資本準備金・繰越利益剰余金を除く
  - 調整項目：期首は入力。当期の留保の加算・減算と名前で突き合わせる
  - 繰越損益金：減に期首、増に期末を書く
  - 納税充当金
  - 未納法人税等・未納道府県民税・未納市町村民税：増に中間分と確定分の合計をマイナスで書く
- 検算：期首現在利益積立金額＋別表四の留保所得−中間分・確定分の法人税等（法人税・地方法人税・防衛特別法人税・住民税）＝差引翌期首現在利益積立金額
  - 合わないとき（配当の入力漏れ、前期分の税額の誤りなど）は差額を出す
- 純資産のうち目印・役割の無い科目（別途積立金・その他資本剰余金・自己株式など）は名前で分けられないので、利益積立金額に入れて注意を出す

## 3. 法人住民税・事業税

- 法人税割
  - 課税標準：差引法人税額（所得税額控除の前）＋足し戻す控除額（入力）。1,000円未満を切り捨てる
  - 標準税率：道府県民税1.0%・市町村民税6.0%（令和元年10月1日以後に開始する事業年度）。東京都の特別区は都民税7.0%
  - 税額は100円未満を切り捨てる
- 均等割
  - 年額×事務所があった月数/12。100円未満を切り捨てる
  - 年額の初期値は、資本金等の額1,000万円以下・従業者50人以下の標準税率（道府県民税2万円・市町村民税5万円、特別区は都民税7万円）
- 税率・年額は自治体ごとに違うので入力で変えられる。分割法人には対応しない
- 出典（地方税なので国税庁の資料が無い。コードには URL を書かない）
  - 総務省「法人住民税・法人事業税」：https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/149767_04.html （均等割の幅 道府県民税2万〜80万円・市町村民税5万〜300万円）
  - 山梨県「法人県民税・法人市町村民税のしくみ」：https://www.pref.yamanashi.jp/documents/6238/houjinjuminzei2.pdf （法人税割 1.0%（制限税率2.0%）・6.0%（制限税率8.4%））
  - 川口市「税率と計算方法」：https://www.city.kawaguchi.lg.jp/material/files/group/23/zeiritutokeisannhouhou.pdf （均等割の表、月割と1か月未満の扱い）
- 中小企業者等の賃上げ促進税制・試験研究費の税額控除などを法人税割の課税標準から引かない扱いは、「足し戻す控除額」で入れる
  - どの控除が対象かは自治体の案内で確かめる前提。条文は未照合
- 事業税の所得金額は、事業税の画面で入力しなければ別表四の所得金額を使う
  - 所得税額控除の分は、法人税で加算したまま事業税でも損金にしない扱いにした（第六号様式別表五の加算の行による推測。記載の手引は未照合）

## 4. 未払法人税等の目安

- 申告で納める税額（各税目の差引納付額のうち、プラスのものの合計）を「計上する額の目安」として出す
- 帳簿の期末の未払法人税等と違えば知らせる
- 別表四は当期利益に納税充当金を足し戻すので、計上額を変えても所得金額は変わらない
- 損益計算書の法人税等と「中間納付額＋未払法人税等への繰入額」が合わないときも知らせる
  - 源泉所得税を法人税等で処理した額（所得税額控除の額）と同じなら、注意は出さない

## 5. 保存と引継ぎ

- 入力は `period.corporateTax`（`saveCorporateTax`）。締めた期間も保存できる
- 項目は任意で、古いデータには無いため、DB_VERSION・BACKUP_VERSION は上げていない（`enterpriseTax` と同じ扱い）
- 「前期の計算から引き継ぐ」は、前期の期間で同じ計算をして、次の3つを入れ直す
  - 欠損金の翌期繰越額
  - 別表五(一)の調整項目の期末
  - 前期分の確定税額（各税目の差引納付額）

## 6. 対応していないもの

- グループ通算制度
- 外国税額控除
- 受取配当等の益金不算入・寄附金の損金算入限度額の計算（別表四の加算・減算に金額を入力する）
- 仮払経理
- 申告期限の延長
- 複数の自治体への分割（第十号様式・均等割の按分）
- 特定同族会社の留保金課税
- 使途秘匿金・土地譲渡利益の税額
- 中小法人以外（資本金1億円超・100億円超）の細かい扱い
- e-Tax 形式（XML）での書き出し
