# 予算と実績（v0.31.0）

## 予算のデータ

- IndexedDB に `budgets` ストアを追加（`DB_VERSION` 5、`periodId` の索引）。バックアップにも含める（`BACKUP_VERSION` 5、v4 からは空で変換）
- レコード：`{ id, periodId, accountId, months: { 'YYYY-MM': 金額 }, createdAt, updatedAt }`。会計期間・科目ごとに1件
  - 金額は区分の向きの0以上の整数（売上も費用も正の数）。0の月は持たない
  - 予算を立てられるのは損益の科目だけ（評価勘定（期末商品棚卸高など）と無効の科目は除く）
- `Repository.saveBudgets(periodId, entries)`：まとめて検証して保存。月がすべて0の科目は予算を消して tombstone を残す。1件でも誤りがあれば何も保存しない
- 自分で追加した科目を削除すると、その科目の予算も消す（tombstone）

## 予算の入力（`#/budget`）

- 科目ごとに年額を入れると月に均等に割る（1円未満の端数は最後の月）。「月別」で月ごとに直せる
- 前期の帳簿があれば「前期の実績から作る」：同じ暦の月の実績×割合（%、1〜999）。1円未満は四捨五入、純額がマイナスの月は入れない
- 入力中に画面を離れるときは確認する

## 予算と実績（`#/reports/budget`）

- 月の範囲を選び、予算と実績をそれぞれ損益計算書の形にして突き合わせる（`js/budget.js` の `budgetVsActual`）
  - 差異＝実績−予算、達成率＝実績÷予算（予算0なら「—」）
  - 段階利益（差引金額・所得、法人は売上総利益〜当期純利益）も同じ形で比べる
- 上に売上の予算と実績のグラフ（月別）、売上と利益（個人は所得）の実績・予算・達成率
- 実績は範囲の月の借方−貸方（決算整理の仕訳も含む）

## 資金繰り表への反映

- 予算があると資金繰り表に「予定に予算を使う」（既定で入、`?budget=0` で切る）
- 予算を入れた科目は、来月から予算の額をその月に入出金する前提で予定にする。その科目の先日付の仕訳・定型仕訳は重ねない
  - 掛けの期間（入金・支払のずれ）は考えない
  - 減価償却費・棚卸高・引当金の繰入繰戻は資金が動かないので予定にしない
