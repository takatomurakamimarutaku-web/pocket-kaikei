# 第2弾 決算書（法人）仕様（v0.22.0）

「帳票 › 決算書（計算書類）」（`#/reports/financial`、法人だけ）。弥生会計・勘定奉行の「決算書」の構成を参考に、次を1つの画面に並べ、印刷で1冊にする（各表の前で改ページ）。

| 表 | 内容 |
|---|---|
| 貸借対照表 | 資産の部・負債の部・純資産の部（株主資本 › 資本金・資本剰余金・利益剰余金〔その他利益剰余金 › 繰越利益剰余金〕・株主資本合計・純資産合計） |
| 損益計算書 | 販売費及び一般管理費は合計の1行（内訳は次の内訳書） |
| 販売費及び一般管理費内訳書 | 販管費の科目と合計 |
| 製造原価報告書 | 製造原価を使う場合だけ |
| 株主資本等変動計算書 | 縦型。科目ごとに 当期首残高・当期純利益・その他の変動（期中の仕訳）・当期末残高 |
| 個別注記表 | 下記 |

## 根拠（2026-10-29 確認）
- 計算書類の種類：会社法 第435条第2項、会社計算規則 第59条
- 個別注記表の項目：会社計算規則 第98条。会計監査人設置会社以外の公開会社でない株式会社は、重要な会計方針に係る事項・会計方針の変更・表示方法の変更・誤謬の訂正・株主資本等変動計算書・その他の注記（弥生会計サポート「個別注記表」の表で確認。e-Gov の条文はこの環境から取得できず、原文は未照合）
- 区分の判定：資本金は role `capital_stock`、資本剰余金は目印 `capital_reserve`、利益剰余金は目印 `legal_reserve` と role `retained_earnings`（法人テンプレートに目印を追加。既存データは起動時にコードで補う）

## 個別注記表
- 重要な会計方針：棚卸資産（残高があるとき。初期値「最終仕入原価法による原価法」）、固定資産の減価償却の方法（空欄なら固定資産台帳の償却方法から文を作る）、引当金（空欄なら貸倒引当金の残高があるとき定型文）、消費税等の会計処理（税込方式）
- 会計方針の変更・表示方法の変更・誤謬の訂正・その他：入力した場合だけ出す
- 貸借対照表に関する注記（任意）：有形固定資産の減価償却累計額
- 株主資本等変動計算書に関する注記：発行済株式の数・自己株式の数・剰余金の配当
- 入力は会計期間のレコード `period.statementNotes` に保存（`saveStatementNotes`。締めた期間でも保存できる）。ストア・バックアップ形式の変更なし

## 未対応
- 評価・換算差額等、新株予約権、自己株式の科目の区分
- 株主資本等変動計算書の変動事由の自動分類（剰余金の配当・積立などは「その他の変動」にまとめる）
- 期の番号（第○期）の表示
