# 源泉徴収票・給与支払報告書・法定調書合計表（第2弾 C-2 ②-b）

年末調整（[spec-phase2-year-end.md](spec-phase2-year-end.md)）の続き。1年分の給与と年末調整の結果から、1人ずつの源泉徴収票（受給者交付用）と給与支払報告書（個人別明細書）を作り、提出の要否・法定調書合計表の欄・市区町村ごとの人数をまとめる。

## 判断と根拠

- **対応は年末調整と同じ令和8年分だけ**：令和7年分以前は提出範囲が違い、令和9年分は年末調整の計算に未対応のため
- **年末調整をした人**（確定・精算済み）：確定したときの結果で作る。家族の欄・区分・摘要は、確定した申告書の内容から作る。確定した後に給与が変わったら注意を出す
- **年末調整をしなかった人**（退職者・乙欄・まだ年末調整をしていない人）：支払った給与・社会保険料・徴収した税額で作る。給与所得控除後の金額・所得控除の額の合計額・家族の欄は空欄（扶養控除等申告書を見て書き足してもらう注意を出す）。乙欄の印は、その年の給与がすべて乙欄のとき
- **退職者の判定**：従業員の「退職した日」がその年にある人。30万円以下の判定は、この支払者がその年に支払った金額（前職分を含めない）
- **住民税の徴収**：その年に退職した人は普通徴収（退職者）として数える。それ以外は従業員の登録の特別徴収・普通徴収
- **マイナンバーは保存しない**：受給者交付用には書かない。給与支払報告書の個人番号は書き足すか、eLTAX などで入力してもらう
- **様式そのものは作らない**：国税庁の受給者交付用の欄の並びに合わせた写し（印刷・PDF）と CSV。国税庁の様式に書き写すときや、e-Tax・eLTAX のソフトに入力するときに使う
- **支払者の欄**：給与の設定の支払者 → 請求書の設定の発行元 → 事業者名の順に使う

## 画面

- 給与計算 › 源泉徴収票・給与支払報告書（`#/payroll/slips?year=2026`）：その年に給与を支払った人の源泉徴収税額・支払金額・提出の要否・確かめること、まとめて印刷、CSV、法定調書合計表の欄（Ⓐ・Ⓑ）、市区町村ごとの人数（特別徴収・普通徴収（退職者）・普通徴収（退職者を除く））
- 1人分（`#/payroll/slips/:employeeId?year=2026`、`&type=report` で給与支払報告書）：受給者交付用の欄の並びの紙面と、確かめること。`:employeeId` が `all` なら全員分（1人1ページで印刷）
- 従業員の登録：住所・生年月日・就職した日・退職した日・給与支払報告書の提出先（市区町村）・住民税の徴収・外国人・死亡退職
- 給与の設定：源泉徴収票の支払者（氏名又は名称・住所・電話番号）
- 年末調整の入力：保険料の「うち国民年金保険料等」（申告による社会保険料の内数）

## データ

- 従業員（employees）に任意の項目を追加：`address`・`birthDate`・`joinedOn`・`retiredOn`・`residentCity`・`residentCollection`（special・ordinary）・`foreigner`・`deceased`。無い記録は空欄・特別徴収・false として扱う
- 給与の設定（settings.payroll）に `payer`（name・address・phone）
- 年末調整の保険料（insurance）に `nationalPension`
- いずれも省略できる項目のため、`DB_VERSION`（索引の追加なし）と `BACKUP_VERSION` は変えない。前の版のバックアップはそのまま読み込める（テストで確認）

## 未確認の事項・対象外

- **様式への印字**：国税庁・市区町村の様式の位置に合わせた印字はしない（欄の並びに合わせた写し）
- **住宅借入金等特別控除の内訳**：居住開始年月日・控除区分・年末残高は保存していないため空欄（書き足してもらう）。可能額だけ出す
- **前の支払者の住所**：保存していないため、摘要に書き足してもらう
- **非居住者の扶養親族（30歳以上70歳未満）の区分 02〜04**：要件の内訳を保存していないため空欄
- **5人目以降の書き方**：番号の付け方（「(5)氏名」）は手引の「括弧付きの番号とともに」に合わせた推測
- **総括表**：市区町村の様式（給与の支払期間・連絡先など）は作らない。人数（特別徴収・普通徴収）だけをまとめる。普通徴収にする理由の符号は市区町村の案内に従って書いてもらう
- **災害者（徴収猶予）・丙欄（日雇い）・非居住者への給与の支払調書**：未対応
- **電子提出（e-Tax・eLTAX）のファイル**：作らない（CSV を見て入力する）
