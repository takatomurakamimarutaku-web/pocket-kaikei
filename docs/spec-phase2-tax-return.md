# 第2弾（6）消費税の申告計算 仕様

税込経理の帳簿から、消費税の申告で納める税額（申告書の主な欄）を計算する。「帳票 › 消費税の申告計算」（`#/reports/tax-return`）。
課税期間は会計期間と同じとする。

## 1. 根拠（2026-10-29 確認。令和8年4月1日現在の法令等）
| 内容 | 出典 |
|---|---|
| 割戻し計算（税込×100/110・7.8%、軽減は100/108・6.24%） | 国税庁 No.6383・No.6391 |
| 端数処理：課税標準額は千円未満、差引税額は百円未満を切り捨て、税額は1円未満切り捨て | 国税庁 No.6371 |
| 地方消費税＝差引税額×22/78（百円未満切り捨て） | 国税庁「消費税及び地方消費税の申告書の書き方（個人事業者用）」 |
| 簡易課税：（課税標準額に対する消費税額−売上の返還等の税額）×みなし仕入率（90/80/70/60/50/40%） | 国税庁 No.6505 |
| 2割特例：令和5年10月1日〜令和8年9月30日の日を含む課税期間。3割特例：個人事業者の令和9年分・令和10年分 | 国税庁「2割特例（3割特例）の概要」 |
| インボイスのない仕入の経過措置：令和8年9月30日まで80%、令和8年10月から2年間70%、令和10年10月から2年間50%、令和12年10月から1年間30%、以後0% | 国税庁「インボイス制度の見直し（令和8年度税制改正）」 |

URL はコード（`js/tax-return.js`）の先頭に記載。

## 2. 税区分の追加
- 「課税仕入10%（インボイスなし）」`purchase_10_ni`、「課税仕入8%（軽減・インボイスなし）」`purchase_8r_ni` を追加
- 控除できる割合は、仕訳の日付で上の経過措置の割合を当てる（同じ課税期間に80%と70%が混ざってもよい）
- 1つの相手からの年間上限（令和8年度改正後1億円）は確認しない

## 3. 計算
| 欄 | 計算 |
|---|---|
| 課税標準額 | 税率ごとに 税込売上×100/110（軽減は100/108）、千円未満切り捨て |
| 消費税額 | 課税標準額×7.8%＋×6.24%（1円未満切り捨て） |
| 控除税額（一般） | 税込仕入×7.8/110＋×6.24/108＋インボイスなし×7.8/110×経過措置の割合 |
| 控除税額（簡易） | 消費税額×みなし仕入率（事業区分は1つだけ選ぶ） |
| 控除税額（2割・3割） | 消費税額×80%・70% |
| 差引税額 | 消費税額−控除税額、百円未満切り捨て（マイナスは還付で1円単位） |
| 地方消費税 | 差引税額×22/78、百円未満切り捨て |
| 納付税額 | 合計−中間納付税額（国税・地方を入力） |

- 売上の返品・値引き（売上の科目の借方）は、売上から差し引いて計算する（申告書は「返還等対価に係る税額」を別に書く。結果は端数の分だけ違うことがある）
- 4つの方法の比較表を出す（その期間に使えない方法は「－」）
- 選んだ方法・事業区分・中間納付税額は会計期間のレコード（`period.taxReturn`）に保存する（ストアは変えない）

## 4. 注意の表示
- 一般課税で課税売上割合が95%未満、または課税売上高が5億円超（選んだ方法で按分。v0.13.0 から。`spec-phase2-tax-categories.md`）
- 簡易・2割・3割でインボイスなしの仕入がある（その方法では仕入の税額を使わない）
- 令和9年4月1日以後を含む期間に軽減税率の売上がある（飲食料品の税率引き下げは未対応）
- 免税事業者の設定なら「申告は不要（参考の計算）」

## 5. 決算整理の仕訳
- 納付税額（中間納付を除いた残り）を期末日に「租税公課 / 未払消費税等」で登録できる（個人で未払消費税等の科目が無ければ未払金）
- 科目は目印 `taxes_dues`・`consumption_tax_payable`・`accrued` で選ぶ。仕訳に `source: 'consumption_tax'` を付け、計算と金額が違えば注意する

## 6. 未対応
- 積上げ計算、複数の事業区分の簡易課税（按分・貸倒れ・返品の区分は v0.13.0 で対応。`spec-phase2-tax-categories.md`）
- 令和9年4月からの飲食料品の税率の引き下げ
- 申告書の様式そのものの出力（e-Tax・確定申告書等作成コーナーへ入力する数字として使う）
