## 洗い出した不足と対応
| 不足 | 対応 |
|---|---|
| 期中増加・期中減少が無く、期中に売却した資産の期末帳簿価額が0にならない | 増減明細（取得価額・帳簿価額の期首／増加／減少／期末）を計算。売却・除却した資産は期末0、売却日の帳簿価額を期中減少 |
| 減価償却累計額が無い | 累計額＝取得価額−帳簿価額（期首・期末） |
| 償却月数が出ない | 台帳・CSV に償却月数 |
| 償却予定表（先の年の償却額）が無い | 当期から5年・10年。登録していない年は12か月の期間で計算 |
| 月次償却額が無い | 当期の償却費を償却する月に均等に割り振る（端数は後の月、特別償却は最後の月、少額は使い始めた月、一括償却は全月） |
| 取得資産・除却資産の一覧が無い | 取得・除売却タブ、取得資産台帳・除却資産台帳（売却損益） |
| 絞り込み・検索・並び替え・集計の切り替えが無い | 状態・科目・種類・部門・文字、集計の単位（科目・種類・設置場所・部門）、並び順 |
| 部門・購入先の項目が無い | 追加。部門は減価償却の仕訳の償却費に付ける |
| 印刷様式が1種類だけ | 6種類（A4横） |

## 計算の決まり
- 期首帳簿価額＋期中増加−当期償却額−期中減少＝期末帳簿価額（テストで確認）
- 期中に取得：その期間に使い始めた資産（前の帳簿から期首の帳簿価額を引き継いだ資産・一部の売却除却で分けた資産は期首からある）
- 一括償却資産は除却しても3年で償却を続けるので、期中減少にしない（従来どおり）
- 月次償却は見積もり（表示・印刷・CSV）。仕訳は従来どおり決算・繰越で期末に1本

## 月次償却の仕訳（v0.70.0）
- 固定資産台帳の「月次償却」で、選んだ月までの未登録の月を、月ごとに月末日の仕訳で登録する（source: 'depreciation'、depMonths: ['YYYY-MM']、adjusting: false＝月次推移では各月に入る）
- 月の額は月次償却額（端数は後の月、特別償却は最後の月）と同じ。部門・個人の私用分（事業主貸）も同じ扱い
- 決算・繰越：月次の仕訳があり残りの月があれば、残りの月の分を期末日の決算整理の仕訳（depMonths: 残りの月）で登録。depMonths の無い仕訳は年1回（全額）とみなし、月次では登録させない
- 資産を直したときは、登録済みの仕訳を削除して登録し直す（台帳の償却費と仕訳の合計が違えば決算・繰越に注意が出る）

## 償却しない資産（v0.71.0）
- 種類「土地」（nonDepreciable）と償却の方法「償却しない」（method: 'none'）。土地は「償却しない」だけ。ほかの種類でも建設仮勘定・美術品・電話加入権などに使える
- 償却の明細は無く、台帳には取得価額のまま。期中取得は期中増加、売却・除却は期中減少（isDisposable）
- 売却の仕訳：土地は非課税売上（国税庁 No.6225「地代、家賃や権利金、敷金など」：土地の譲渡や貸付けは非課税。消法6・別表第2の一）、それ以外は課税売上10%
- 除外：減価償却の仕訳、青色申告決算書・収支内訳書の減価償却費の計算、償却資産申告（対象外で固定）、別表十六（定額法・定率法だけ）、一部の売却除却・資本的支出

## 資産の移動（v0.73.0）
- 資産に `moves`（日付の順）を持つ。1件は `{ id, date, fromDepartmentId, fromLocation, toDepartmentId, toLocation, memo }`
- 今の部門・設置場所（`departmentId`・`location`）は最後の移動の移動後と同じにする（検証で確認）。移動の履歴があるときは、資産の画面で部門・設置場所を直接は変えられない
- 移動した日の属する月から移動後の部門・設置場所（`placeAt`）。日割りはしない
- 期中に部門を移した資産の償却費（経費になる額）は、月次償却額（`monthlyDepreciation`）を月ごとの部門で足して分ける（`departmentSplit`）。決算・繰越の仕訳も月次償却の仕訳も同じ割り振りで、合計と貸借は変わらない
- 一部の売却・除却で分けた資産には、売却・除却した日までの移動だけを引き継ぐ
- 帳票：「取得・除却・移動」に当期の移動の一覧、印刷に「移動資産台帳」
- 最後の移動だけ取り消せる。登録済みの減価償却の仕訳は変えない（登録し直す）
- 集計の単位（部門・設置場所ごと）は今の部門・設置場所で分ける

## 圧縮記帳（v0.75.0）
- 出典（2026-10-31 確認）
  - 国税庁「圧縮記帳に関する会計処理及び表示について」https://www.nta.go.jp/law/tsutatsu/kobetsu/hojin/760515/01.htm （直接減額方式：圧縮損を計上し、同額を取得価額から減額）
  - 別表十三（一）の様式 https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hojin/shinkoku/itiran2022/pdf/13(01).pdf （圧縮限度額は「−1円」＝帳簿価額を1円以上残す）
  - 国税庁 No.2202「国庫補助金等を受け取ったとき」https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2202.htm （個人：総収入金額に算入せず、取得費から補助金等を差し引いた額で減価償却。所得税法42条）
  - 圧縮記帳後の金額が減価償却の取得価額とみなされる（法人税法施行令54条。国税庁 文書回答の解説 https://www.nta.go.jp/law/joho-zeikaishaku/hojin/020404-2/01/12_2_2_3.htm ）
  - 償却資産申告は圧縮前の取得価額（固定資産税に圧縮記帳の制度は無い。例：八代市の申告の手引き）
- データ：`cost` は圧縮後の取得価額、`compressionAmount`（圧縮額）・`compressionOn`・`compressionName`。圧縮前＝cost＋compressionAmount（`costBeforeCompression`）
- 対象：定額法・定率法・償却しない資産（`canCompress`）。少額・一括・中小特例は取得価額で判定するので対象外。一部の売却除却とは併用しない
- 時期：使い始めた会計期間の中（`compressionErrors`）。使い始めた後の期間の圧縮記帳（既償却額の調整）・積立金方式・未決算特別勘定は未対応
- 仕訳（source: 'asset_compression'）：法人 固定資産圧縮損 / 資産、個人 事業主借 / 資産（補助金等の入金は 普通預金 / 事業主借）。法人テンプレートに 721 国庫補助金受贈益・732 固定資産圧縮損。無い帳簿は登録時に 732〜 の空き番号で作る
- 別表十三（一）Ⅰ（v0.77.0）：js/schedule13.js・#/reports/schedule13。当期に圧縮記帳した資産ごとに 補助金等の名称・交付した者・年月日・補助金等の額（compressionSubsidy。空欄は圧縮額）・取得価額（圧縮前）・圧縮限度額（補助金等の額。取得価額以上なら取得価額−1円）・減額した金額・圧縮限度超過額。欄の番号は様式の改正で変わり、今の様式の本文を機械で読めなかったので付けない（記載の仕方 itiran2026 を参照）。申告書の別表（CORPORATE_SHEETS）には入れず、別表十六と同じ別の画面にした

## 並び順・絞り込み・小計の名前（v0.81.0）
- 並び順（SORT_KEYS）：資産番号・勘定科目（コード）・種類・部門（部門の並び順）・設置場所・取得日・使い始めた日・名前・取得価額・当期償却費・期末帳簿価額（大きい順）・耐用年数（短い順）。指定なし・空欄は最後、同じなら資産番号・名前
- 絞り込み：状態・勘定科目・種類・部門・設置場所・償却方法・取得日の範囲・文字
- 集計の単位に「集計しない」。見出しは「勘定科目：工具器具備品」、小計は「工具器具備品 計（3件）」（groupTitle・subtotalLabel）。科目ごとに集計しない印刷では摘要に科目名
