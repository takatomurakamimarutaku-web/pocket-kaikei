## 洗い出した不足と対応
| 不足 | 対応 |
|---|---|
| 期中増加・期中減少が無く、期中に売却した資産の期末帳簿価額が0にならない | 増減明細（取得価額・帳簿価額の期首／増加／減少／期末）を計算。売却・除却した資産は期末0、売却日の帳簿価額を期中減少 |
| 減価償却累計額が無い | 累計額＝取得価額−帳簿価額（期首・期末） |
| 償却月数が出ない | 台帳・CSV に償却月数 |
| 償却予定表（先の年の償却額）が無い | 当期から5年・10年。登録していない年は12か月の期間で計算 |
| 月次償却額が無い | 当期の償却費を償却する月に均等に割り振る（端数は後の月、特別償却は最後の月、少額は使い始めた月、一括償却は全月） |
| 取得資産・除却資産の一覧が無い | 取得・除売却タブ、取得資産台帳・除却資産台帳（売却損益） |
| 絞り込み・検索・並び替え・集計の切り替えが無い | 状態・科目・種類・部門・文字、集計の単位（科目・種類・設置場所・部門）、並び順 |
| 部門・購入先の項目が無い | 追加。部門は減価償却の仕訳の償却費に付ける |
| 印刷様式が1種類だけ | 6種類（A4横） |

## 計算の決まり
- 期首帳簿価額＋期中増加−当期償却額−期中減少＝期末帳簿価額（テストで確認）
- 期中に取得：その期間に使い始めた資産（前の帳簿から期首の帳簿価額を引き継いだ資産・一部の売却除却で分けた資産は期首からある）
- 一括償却資産は除却しても3年で償却を続けるので、期中減少にしない（従来どおり）
- 月次償却は見積もり（表示・印刷・CSV）。仕訳は従来どおり決算・繰越で期末に1本

## 今回やらなかったこと（候補）
- 月次償却の仕訳登録（月ごとに仕訳を作り、期末は残りを登録する）
- 土地など償却しない資産（非償却資産）の登録
- 資産の移動（部門・設置場所の変更履歴）、圧縮記帳、増加償却
