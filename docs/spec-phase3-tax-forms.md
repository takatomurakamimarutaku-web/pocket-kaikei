# 申告書の印刷様式（国税庁の様式の欄の並び）

2026-10-30。たかとさんの依頼「法人税の別表・消費税の申告計算・所得税の申告書を国税庁の様式に寄せる（法人→消費→所得の順）」。

## 方針

- 様式そのもの（OCR の枠・記入欄の位置・文字の大きさ）は再現しない。**欄の番号・行の名前と並び・列の組み方**を様式に合わせ、書き写す・申告ソフトの入力と見比べるための写しにする
- 組版は帳票と同じ `js/print-layout.js`。申告書の内容は `js/print-tax-forms.js`（純粋関数）で作る
- 別表・表ごとに改ページし、ページの表題を様式の名前にする（見出しの `title`）。印刷条件で全部か1つかを選ぶ
- 組版に足したもの：見出しの2段（`headGroups`。別表四の「処分」、別表五(一)の「当期の増減」、別表五(二)の「当期中の納付税額」）、見出しだけ右の列とまとめる列（`headSpan`・`joinLeft`。社外流出③の「その他・※」と金額）、見出しの文字が3行以上なら見出しの段を高くする

### 事実と推測

- 様式・記載要領で確かめた番号：別表四の全部の行と③の印（令和7年版）、別表五(一)・五(二)・七(一)の番号（令和7年版）、別表一の 1・4・9・12・13・16・20・21・23・25・28・43・45・47・48・62・65・74・75・77・79・85・86・89（令和8年版の記載要領）と、式「(2)－(3)＋(4)＋(6)＋(9の外書)」の 2・3・6
- 推測：別表一の 5〜8・10・11・14・15・17〜19・22・24・26・27（番号の並びから）、地方法人税の 29〜42（令和7年版の別表一の並びと同じとみなした）、76・78（74〜79 の並びから）
- 防衛特別法人税の課税標準法人税額・税額・中間申告分・差引確定の番号は確かめられなかったため空欄にした
- 令和8年版の別表四・五(一)・五(二)で、防衛特別法人税が行の名前（2「損金経理をした法人税及び地方法人税」、五(一)の27）に加わったかは確かめられなかった。五(一)の27は「※防衛特別法人税を含む」と添えた
- 別表四に入力した加算・減算の行は、名前で様式の行に当てはめる（附帯税→5、償却超過額→6、役員給与→7、認容額→12、受取配当→14、中間納付額及び過誤納→18、所得税額等及び欠損金→19、寄附金→27）。当てはまらない行は空き行 10・21 とその下に書く。寄附金は 23 仮計に入れず 27 で足す（計算の結果の所得金額は変わらない）

## 消費税（第一表・第二表・付表）

- 欄の番号と名前は `js/tax-forms.js`（国税庁「申告書の書き方」で照合済み。出典はそのファイルの先頭）

- 第二表：左に課税標準額の内訳、右に消費税額・返還等対価・地方消費税の課税標準
- 付表1-3・2-3・4-3・5-3・6：様式と同じく「税率6.24%適用分 A・税率7.8%適用分 B・合計 C（A＋B）」の列

## 所得税（確定申告書）

- 欄の番号は `js/income-tax.js` と画面（第一表の ㋐〜㋗・①〜53）
- 第一表：様式と同じ左右2段。左に収入金額等・所得金額等・所得から差し引かれる金額、右に税金の計算・その他
- 第二表：所得の内訳（給与）・保険料控除等に関する事項・配偶者や親族に関する事項
- 第四表（損失申告用）は純損失・繰越損失がある年だけ、医療費控除の明細書は医療費を入力したときだけ選べる

## 申告書の頭書き（提出者の欄）（v0.76.0）

- 2026-10-31 たかと「各種申告書の帳票様式や内容が質素。他の会計ソフト・税務申告ソフト・国税庁の情報を参考にブラッシュアップ」
- 市販の申告ソフト（達人・JDL・弥生・freee の申告）は様式そのものを印刷するが、このアプリは様式の枠を再現しない方針（PR #63）。
  その代わり、様式の頭書きの項目（提出日・提出先・納税地・名称・番号・代表者・事業年度など）を、項目名を薄く塗った2組の欄の表で最初のページの上に置く（`js/print-form-heads.js`）
- 入力は `settings.filer`（「事業者の設定 › 申告書の提出者」、`js/filer.js`）。DB の版は変えない（設定の中の項目。バックアップにも入る）
- マイナンバー（個人番号）は保存しない。個人番号の欄は常に空欄で印刷する（端末に置く個人情報を増やさない）。法人番号は公表される番号なので保存する
- 法人番号の検査用数字：国税庁 法人番号公表サイト「チェックデジットの計算方法」 https://www.houjin-bangou.nta.go.jp/documents/checkdigit.pdf （例 700110005901 → 8700110005901 をテストで確認）
- 様式ごとの頭書きの項目
  - 法人税（別表一）：提出日・○○税務署長殿・納税地・電話・法人番号・フリガナ・法人名・代表者・経理責任者・事業種目・資本金の額・法人区分・申告区分・事業年度・関与税理士
  - 第六号様式・第二十号様式：提出日・宛名（都道府県知事／都税事務所長、市町村長）・所在地・法人番号・代表者・事業種目・資本金の額・資本金等の額・従業者数・事業年度と月数
  - 消費税（第一表）：納税地・名称（屋号）・法人番号（個人は個人番号の空欄）・代表者氏名（氏名）・課税期間
  - 所得税（第一表）：住所・フリガナ・氏名・職業・屋号・雅号・電話・個人番号（空欄）
  - 青色申告決算書・収支内訳書：住所・事業所所在地・フリガナ・氏名・業種名・屋号・電話・加入団体名・依頼税理士等
  - 償却資産申告書：宛名（市町村長）・住所（本店所在地）・名称（氏名）・代表者・法人番号・事業種目

## 申告書を国税庁の様式に合わせる（v0.87.0）

- 目標：印刷すればそのまま申告に使える細かさ（2026-10-31 たかと）。進める順は法人税→消費税→所得税
- 見出し：申告書の印刷は、左上に別表の番号、中央に様式名（長いときは「に関する」で2行）、右上に事業年度（消費税は課税期間、所得税は年分）と法人名（氏名）の枠。作成日・アプリ名・ページ番号は出さない
- 別表二（同族会社等の判定に関する明細書）を追加。様式：https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hojin/shinkoku/itiran2025/pdf/02.pdf （2026-10-31 に PDF の文字で確認）
  - (1)発行済株式の総数、(2)＝(19)と(21)の上位3順位の株式数、(3)＝(2)/(1)、(4)〜(6)議決権、(10)＝(3)(6)(9)のうち最も高い割合
  - (11)＝(21)の上位1順位、(13)＝(22)の上位1順位：特定同族会社の判定は「被支配会社でない法人株主等」(19)(20)を除いて数える
  - (17)＝(12)(14)(16)のうち最も高い割合、(18)判定結果。特定同族会社は資本金1億円以下の中小法人を除く（法人税法67条）
  - 社員の数による判定（(7)〜(9)・(15)(16)）は持分会社のもので扱わない（空欄）
  - 割合は1/1000%単位で切捨て、表示は小数1位
- 照合済み：別表四（簡易様式）の行番号（1〜52、28・33・35・36・42・46〜50 の欠番を含む）と別表五(一)の行番号（1〜36）は令和7年4月1日以後終了事業年度分の様式と一致
- これから：別表六(一)、適用額明細書、法人事業概況説明書、消費税の付表、所得税の第一表・第二表と青色申告決算書（OCR 様式は国税庁の OCR 帳票仕様書を取り寄せてから）

## 別表六(一) 所得税額の控除に関する明細書（v0.88.0）

- 様式：https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hojin/shinkoku/itiran2025/pdf/06(01).pdf （令和7年4月1日以後終了事業年度分、2026-10-31 に PDF の文字で確認）
- 区分 1 利子等・2 剰余金の配当等・3 集団投資信託の収益の分配・4 割引債の償還差益・5 その他・6 計。欄は ①収入金額 ②①について課される所得税額 ③②のうち控除を受ける所得税額
- 2〜4 は個別法（7〜12）：(11) 所有期間割合＝(10)/(9)（小数点以下3位未満切上げ）、(12)＝(8)×(11)。計算期間を入れない行は全額を控除
  - (12) の円未満は切り捨てにした（様式に端数の定めが書かれていないため、控除額を多くしない側に寄せた。推定）
  - 銘柄別簡便法（13〜19）は計算しない（印刷は空欄の枠だけ）
- 5 その他は支払者ごとの明細（20 収入金額・21 控除を受ける所得税額）
- 明細を入れると、6の③が「法人税額から控除される所得税額」（別表四の加算・別表一の控除税額）になる。入れなければ従来どおり金額を直接入力
- 明細は期ごとのもので、前期からは引き継がない

## 法人事業概況説明書（v0.94.0）

- 出典：記載要領（令和6年3月1日以後終了事業年度分）https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hojin/shinkoku/pdf/0021004-100.pdf （2026-10-31 に PDF の文字で確認）

- 帳簿から書く欄（千円未満切捨て、0は空欄、マイナスは△）
