# 申告書の印刷様式（国税庁の様式の欄の並び）

2026-10-30。たかとさんの依頼「法人税の別表・消費税の申告計算・所得税の申告書を国税庁の様式に寄せる（法人→消費→所得の順）」。

## 方針

- 様式そのもの（OCR の枠・記入欄の位置・文字の大きさ）は再現しない。**欄の番号・行の名前と並び・列の組み方**を様式に合わせ、書き写す・申告ソフトの入力と見比べるための写しにする
- 組版は帳票と同じ `js/print-layout.js`。申告書の内容は `js/print-tax-forms.js`（純粋関数）で作る
- 別表・表ごとに改ページし、ページの表題を様式の名前にする（見出しの `title`）。印刷条件で全部か1つかを選ぶ
- 組版に足したもの：見出しの2段（`headGroups`。別表四の「処分」、別表五(一)の「当期の増減」、別表五(二)の「当期中の納付税額」）、見出しだけ右の列とまとめる列（`headSpan`・`joinLeft`。社外流出③の「その他・※」と金額）、見出しの文字が3行以上なら見出しの段を高くする

### 事実と推測

- 様式・記載要領で確かめた番号：別表四の全部の行と③の印（令和7年版）、別表五(一)・五(二)・七(一)の番号（令和7年版）、別表一の 1・4・9・12・13・16・20・21・23・25・28・43・45・47・48・62・65・74・75・77・79・85・86・89（令和8年版の記載要領）と、式「(2)－(3)＋(4)＋(6)＋(9の外書)」の 2・3・6
- 推測：別表一の 5〜8・10・11・14・15・17〜19・22・24・26・27（番号の並びから）、地方法人税の 29〜42（令和7年版の別表一の並びと同じとみなした）、76・78（74〜79 の並びから）
- 防衛特別法人税の課税標準法人税額・税額・中間申告分・差引確定の番号は確かめられなかったため空欄にした
- 令和8年版の別表四・五(一)・五(二)で、防衛特別法人税が行の名前（2「損金経理をした法人税及び地方法人税」、五(一)の27）に加わったかは確かめられなかった。五(一)の27は「※防衛特別法人税を含む」と添えた
- 別表四に入力した加算・減算の行は、名前で様式の行に当てはめる（附帯税→5、償却超過額→6、役員給与→7、認容額→12、受取配当→14、中間納付額及び過誤納→18、所得税額等及び欠損金→19、寄附金→27）。当てはまらない行は空き行 10・21 とその下に書く。寄附金は 23 仮計に入れず 27 で足す（計算の結果の所得金額は変わらない）

## 消費税（第一表・第二表・付表）

- 欄の番号と名前は `js/tax-forms.js`（国税庁「申告書の書き方」で照合済み。出典はそのファイルの先頭）
- 第一表：左に「この申告書による消費税の税額の計算」①〜⑫と⑮⑯、右に「地方消費税の税額の計算」⑰〜㉓と㉖
- 第二表：左に課税標準額の内訳、右に消費税額・返還等対価・地方消費税の課税標準
- 付表1-3・2-3・4-3・5-3・6：様式と同じく「税率6.24%適用分 A・税率7.8%適用分 B・合計 C（A＋B）」の列
- 「計算の内容」を表示しているときは、これまでの画面の表（計算の内容・方法ごとの比較）も選べる

## 所得税（確定申告書）

- 欄の番号は `js/income-tax.js` と画面（第一表の ㋐〜㋗・①〜53）
- 第一表：様式と同じ左右2段。左に収入金額等・所得金額等・所得から差し引かれる金額、右に税金の計算・その他
- 第二表：所得の内訳（給与）・保険料控除等に関する事項・配偶者や親族に関する事項
- 第四表（損失申告用）は純損失・繰越損失がある年だけ、医療費控除の明細書は医療費を入力したときだけ選べる
