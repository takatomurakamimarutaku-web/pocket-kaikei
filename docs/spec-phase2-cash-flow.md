# キャッシュフロー計算書と資金繰り表（v0.30.0）

## キャッシュフロー計算書（間接法、`#/reports/cash-flow`）

- 資金＝現金・預金（役割 `cash`・`deposit`）。定期預金も含める（3か月を超える定期預金を除く厳密な区分はしない）
- 期首残高（`openingRows`）と期末残高（`closingRows`）の差額、損益計算書の金額から作る（`js/cash-flow.js`）
- 各行の合計は必ず「期末の資金−期首の資金」に一致する（一致しないのは期首残高の貸借がずれているとき。画面で知らせる）
  - 資金の増減＝利益＋資金以外の貸借対照表の科目の増減（資産は減ると＋、負債・純資産は増えると＋）

| 区分 | 行 | 中身 |
|---|---|---|
| 営業 | 税引前当期純利益（法人）／所得金額（個人、青色申告特別控除前） | 損益計算書 |
| 営業 | 減価償却費 | 目印 `depreciation`・`mfg_depreciation` の科目の金額 |
| 営業 | 固定資産売却損益・除却損（法人） | `asset_sale_loss`＋`asset_retirement_loss`−`asset_sale_gain` |
| 営業 | 貸倒引当金の増減（法人） | `allowance_doubtful` |
| 営業 | 売上債権・棚卸資産・仕入債務の増減 | 手形・売掛金／商品・製品・原材料・仕掛品・貯蔵品／手形・買掛金 |
| 営業 | その他の資産・負債の増減 | 上と下のどれにも入らない流動資産・負債（固定負債のうち借入金以外も含む） |
| 営業 | 法人税等の支払額（法人） | 未払法人税等（目印 `income_taxes_payable`）の増加−法人税等 |
| 投資 | 固定資産の取得・売却（純額） | 有形・無形固定資産の増減から、減価償却費と売却損益を除いたもの |
| 投資 | 貸付金・有価証券の増減 | `short_loan`・`securities` |
| 投資 | 投資その他の資産の増減 | 投資その他の資産・繰延資産 |
| 財務 | 借入金の増減 | `short_borrowings`・`long_borrowings`・`officer_loan` |
| 財務 | 資本金・剰余金の増減（法人） | 純資産の科目の増減（当期純利益を除く＝増資・配当など） |
| 財務 | 事業主との出し入れ（個人） | 事業主借・元入金の増減−事業主貸の増減 |

- 利息の受取・支払は営業活動に含める（中小企業向けの簡便な形。「小計」の下に利息を分ける様式にはしない）
- フリーキャッシュフロー（営業＋投資）を上に出す
- 目印の追加：法人の未払法人税等に `income_taxes_payable`、個人の貸付金に `short_loan`・借入金に `short_borrowings`（既存の帳簿は起動時の `fillAccountHints` で補う）

## 資金繰り表（`#/reports/cash-plan`）

- 月ごとの 月初の残高／収入／支出／経常の収支／設備・財務／月末の残高。グラフは月の収支（棒）と月末残高（線）
- 仕訳のうち現金・預金の行を含むものだけを使い、相手の行（資金以外の行）の科目で分ける。貸方なら入金、借方なら出金
  - 口座間の移動（資金どうし）は収支にしない。資金の動かない仕訳（掛け売上など）は対象外
  - 売上の入金：売上の区分・売掛金・受取手形・前受金／仕入の支払：売上原価・製造原価の区分・買掛金・支払手形・前払金
  - 経費の支払：経費（販管費）・営業外費用・専従者給与・未払金・未払費用／税金の支払：法人税等・租税公課・未払消費税等・未払法人税等
  - 設備・投資：固定資産・投資その他・繰延資産・貸付金・有価証券／借入れ・返済：借入金の目印／事業主・資本：事業主貸・純資産の区分
  - どれにも入らない科目（仮払金・預り金など）は、入金なら「その他の収入」、出金なら「その他の支出」
- 今月までは実績。来月からは予定：先の日付で登録した仕訳＋まだ作っていない毎月の定型仕訳（現金・預金を使うもの）
  - 予定の列は色を変え、グラフは薄い棒・破線。予定の月末で残高がマイナスになる月があれば知らせる
- 横にスクロールする月別の表で、科目の列を固定する（`.report` の `overflow` を `clip` にして、既存の月次推移表・月次推移試算表でも左の列が固定されるようになった）
