# 前期比較と経営分析（v0.29.0）

## 前期比較（損益計算書・貸借対照表）

- 損益計算書・貸借対照表の画面に「前期と比べる」（貸借対照表は「期首と比べる」「前期末と比べる」）の切替を置く。`?compare=1` で開ける
- 列：科目／当期／前期／増減（下に増減率）
  - 増減率＝（当期−前期）÷｜前期｜。前期が0なら「—」。表示は小数1桁（‰の整数で持つ。金額の計算には使わない）
  - 赤字が縮んだ（−100万→−50万）ときはプラスになる
- 前期の数字
  - 損益計算書：前期の帳簿（当期の開始日の前日に終わる期間）がアプリにあれば、その期間で集計する。無ければ前期の列は空欄で、案内を出す
  - 貸借対照表：当期の期首残高（前期末の残高を繰り越したもの）から作る。前期の帳簿が無くても比べられる
    - 個人：青色申告決算書の貸借対照表も「期首」「期末」の2列。期首の事業主貸・事業主借は0、所得は期末の列だけ
    - 法人：前期末の繰越利益剰余金には前期の当期純利益が含まれる。「うち当期純利益」の行は前期を比べない（「—」）
- 行の突き合わせ（`js/compare.js`）：区分は見出し、科目は id、段階利益は名前（同じ名前が2つある個人の「差引金額」は出てくる順）で合わせる。前期にしかない科目は同じ区分の合計の前に入れる
- 「0円の科目も表示」を外すと、当期・前期とも0の科目と、中身がすべて0の区分を隠す

## 経営分析（`#/reports/analysis`）

当期と前期を並べる。前期は「前期の損益（前期の帳簿があれば）」と「当期の期首残高＝前期末の残高」から求める。前期の帳簿が無いときは、残高だけで求められる指標（安全性・運転資本）だけを出す。

| 区分 | 指標 | 計算式 |
|---|---|---|
| 収益性 | 売上総利益率 | （売上−売上原価）÷売上 |
| 収益性 | 営業利益率・経常利益率（法人） | 営業利益・経常利益÷売上高 |
| 収益性 | 所得率（個人） | 青色申告特別控除前の所得金額÷売上(収入)金額 |
| 安全性 | 流動比率 | 流動資産÷流動負債 |
| 安全性 | 当座比率 | 当座資産（現金・預金・売上債権・有価証券、貸倒引当金を控除）÷流動負債 |
| 安全性 | 自己資本比率 | 純資産÷総資産（個人は（元入金＋事業主借−事業主貸＋所得）÷（資産合計−事業主貸）） |
| 安全性 | 固定比率 | 固定資産÷純資産（自己資本） |
| 効率性 | 売上債権・棚卸資産・仕入債務の回転期間 | 残高÷月平均の売上（月数は会計期間の月数） |
| 効率性 | 運転資本とその回転期間 | 売上債権＋棚卸資産−仕入債務、その÷月平均の売上 |
| 損益分岐点 | 変動費・固定費・限界利益率・損益分岐点売上高・損益分岐点比率・安全余裕率 | 変動費＝売上原価、固定費＝限界利益−利益（法人は経常利益、個人は所得） |

- 分母が0以下の指標は「—」。損益分岐点売上高は1円未満を四捨五入
- 回転期間は月商（売上）を分母にそろえた（金融機関の見方に合わせた簡便な形）。売上原価を分母にする流儀もある
- 損益分岐点は簡便な勘定科目法。外注費など売上に連動する経費が多いと、実際より高めに出る
- 科目は区分・役割・目印で集める（`js/analysis.js`）
  - 個人のテンプレートの受取手形・有価証券・支払手形に目印（`notes_receivable`・`securities`・`notes_payable`）を追加。既存の帳簿は起動時の `fillAccountHints` で補われる
- 損益計算書の `profits` に売上・売上原価・販管費（経費）の合計（法人は営業外収益・費用も）を加えた

## 未確認・未対応

- 業種別の平均値（中小企業実態基本調査など）との比較は入れていない。指標の水準の判断は利用者に委ねる
- 変動費・固定費を科目ごとに選ぶ（固変分解の設定）は未対応
- 前期の帳簿が無い利用者が、前期の損益を手で入れる機能は未対応
