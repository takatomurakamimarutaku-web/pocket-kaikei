# 償却資産申告書・事業税（v0.23.0）

## 1. 償却資産申告書（`js/property-tax.js`・`#/reports/property-tax`）

固定資産台帳から、申告する年度（賦課期日＝その年の1月1日）の申告書と種類別明細書を作る。弥生会計・freee の償却資産申告と同じ考え方。

- 振り分け：前年1月1日に持っていた資産＝（イ）、そのうち前年中に売却・除却した資産＝（ロ）、前年1月2日〜1月1日に取得して持っている資産＝（ハ）、（ニ）＝（イ）−（ロ）＋（ハ）
- 評価額（参考）：取得の翌年度は 取得価額×（1−r/2）、以後は 前年度の評価額×（1−r）。1円未満切捨て、取得価額の5%が下限。r は固定資産評価基準 別表第15
  - 減価残存率は大分市「減価率表」の2〜50年すべてとテストで照合。甲府市の計算例（3資産・課税標準額3,337,000円・税額46,700円）と一致
- 課税標準額は1,000円未満切捨て、税額は1.4%で100円未満切捨て、150万円未満は免税点
- 対象外：建物・無形・一括償却・10万円未満の少額（変えられない）。建物附属設備と車両は「確認が必要」として初期値は対象外、資産ごとに対象にできる。少額特例（30万円・40万円未満）は対象
- 台帳に任意の項目を追加：`ptInclude`（'yes'|'no'|null）・`ptKind`（1〜6）・`ptLife`（少額特例など耐用年数の無い資産用）。古いデータには無いため、DB_VERSION・BACKUP_VERSION は上げていない（v0.14.0 の assetNo などと同じ扱い）

未対応・未確認：短縮耐用年数・増加償却・課税標準の特例・非課税、複数市区町村、個人の家事兼用資産の扱い（全額で計算）、1月1日取得を前年中取得とする扱いは推測。

## 2. 事業税（`js/enterprise-tax.js`・`#/reports/enterprise-tax`）

### 法人（第六号様式の所得割・特別法人事業税）
- 資本金1億円以下の普通法人（外形標準課税の対象外）。標準税率 3.5%・5.3%・7.0%、軽減税率不適用は7.0%（茨城県の税率表で確認）。超過税率は入力で変えられる
- 所得割＝各区分の金額×税率（1円未満切捨て）の合計を100円未満切捨て。区分の金額は月数が12未満なら月割し1,000円未満切捨て（推測。様式の記載要領は未照合）
- 特別法人事業税＝標準税率で計算した所得割額（基準法人所得割額）×37%、100円未満切捨て
- 所得金額は既定で「法人税の申告」の別表四の所得金額（v0.49.0 から。それまでは税引前当期純利益）。詳細は [spec-phase2-corporate-tax.md](spec-phase2-corporate-tax.md)
- 入力は `period.enterpriseTax`（`saveEnterpriseTax`）

### 個人（個人事業税の見込み）
- 課税標準＝所得金額（青色申告特別控除前）−損失の繰越控除など−事業主控除（290万円、1年未満は月割の表）。1,000円未満切捨て
- 税率：第1種5%・第2種4%・第3種5%（あん摩等3%）・非課税業種。100円未満切捨て。1万円超は2回払い（第2期の1,000円未満は第1期へ）
- 出典：滋賀県「個人事業税」

未対応：外形標準課税・分割法人・不動産所得（法人住民税は v0.49.0 の「法人税の申告」で計算）・白色の専従者控除・事業用資産の譲渡損失。
