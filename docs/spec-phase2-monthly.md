# 第2弾（2）月次推移表・グラフ 仕様

帳票メニューの「月次推移表」（`#/reports/monthly`）。保存形式は変えない（集計の表示だけ）。

## 損益（月ごと）
- 会計期間の各月について、その月の発生額で損益計算書と同じ区分・段階利益を並べる（`monthly.js` の `monthlyIncome()`）
- 区分・段階利益の計算は `statements.js` の `incomeStatement()` をそのまま使うので、月別の合計は損益計算書と一致する（テストで確認）
- 合計の列を付ける。0円の科目は初期状態で隠す
- グラフ：月別の売上（棒）と利益（折れ線。法人は当期純利益、個人は青色申告特別控除前の所得金額）
  - 同じ単位（円）なので軸は1本。目盛りは「万」「億」で短く表示、マイナスは △
  - 月をタップすると、その月の値をグラフの下に表示する
  - 配色はグラフ用の CSS 変数 `--chart-1`・`--chart-2`。ライト・ダークで別の段階を使い、色覚の多様性の検証（ΔE）を通した値

## 貸借（月末残高）
- 各月末の残高で貸借対照表の区分を並べる（`monthlyBalance()`）。毎月末で資産合計＝負債・純資産合計になることをテストで確認
- 一致しない月があれば注意を表示する

## CSV
- 表示中の表を CSV で書き出す（区分の行は【区分名】、科目の行は先頭に全角空白。金額は -1000 形式）

## 月次推移試算表（v0.15.0、`#/reports/trial-monthly`）

残高試算表を月ごとに横に並べる帳票。たかとの依頼（2026-10-29）。

- 列：繰越残高（開始月の前日まで）・各月・合計。期間は月の範囲で選ぶ
- 貸借の科目は各月末の残高、損益の科目はその月の発生額（いずれも科目の残高側の金額。マイナスは △）
- 表示オプション（URL の `q=1`・`hy=1`・`adj=1`・`zero=1` に残る）
  - 四半期の合計：会計期間の最初の月から3か月ごと（第1〜第4四半期）。最後の月の後ろに置き、範囲外の月は含めない。貸借の科目は四半期末の残高
  - 半期の合計：6か月ごと（上半期・下半期）
  - 決算整理を別の列に：決算整理仕訳を月の数字から外し、「決算整理」の列に出す（損益は決算整理の発生額、貸借は決算整理後の残高）。合計には含める
  - 0円の科目も表示
- 区分ごとの小計の行（評価勘定は差し引く）。科目名から総勘定元帳へ移動できる
- CSV（区分の行は【区分名】、科目の行は先頭に全角空白、金額は -1000 形式）と印刷に対応

### 決算整理仕訳の判定（`monthly.js` の `isAdjusting`）

1. 仕訳の `adjusting`（真偽値）があればそれに従う。振替伝票に「決算整理仕訳」のチェックを追加した
2. 無ければ作った画面で判定：減価償却（`source: 'depreciation'`）・消費税等（`consumption_tax`）・期末棚卸（`inventory`。v0.15.0 から付ける）
3. それより前に登録した期末棚卸の仕訳には印が無いので、摘要が「決算整理」で始まる仕訳も決算整理とみなす

保存形式：仕訳に任意の `adjusting` を追加（真偽値以外は検証で拒否）。ストア・バックアップの版は変えない。
