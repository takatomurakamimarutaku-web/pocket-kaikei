# 第2弾：印刷/PDF

> v0.53.0 で、帳票は印刷専用の様式（A4・繰越行・ページ番号）で組んだ印刷プレビューと PDF の書き出しに変えた。今の仕様は `docs/spec-phase3-print-forms.md`。この文書の「印刷用の表示」は、請求書・給与明細・源泉徴収票（ブラウザの印刷のまま）と、印刷プレビューの元の画面にだけ当てはまる。

帳票を紙に印刷する、または PDF で保存できるようにする。専用の PDF ライブラリは使わず（外部CDN不使用・ビルド不要の方針）、ブラウザの印刷機能と印刷用のスタイル（`@media print`）で作る。

## 使い方

- 帳票の画面では、ヘッダーの右上に印刷ボタン（プリンターの絵）が出る。押すとブラウザの印刷画面が開く。
- iPhone の Safari では、印刷画面でプレビューを開き「共有」→「ファイルに保存」で PDF にできる。
- 対象の画面（`app.js` のルートに `print: true`）：仕訳帳、出納帳、総勘定元帳、残高試算表、月次推移表、損益計算書、貸借対照表、消費税集計、消費税の申告計算、青色申告決算書、固定資産台帳。

## 印刷用の表示

- 白地・黒字（ダークモードでも印刷は明るい配色）。A4縦、余白10mm。
- ヘッダー・下部タブ・ボタン・チェックボックス・検索欄・切り替え（segmented）・`.no-print` を付けた部品は出さない。選択欄（月の範囲・科目）は文字だけを出す。
- 先頭に印刷の見出し（帳票名・事業者名・会計期間・印刷日）を出す（`#print-head`、画面では非表示）。
- 表は横スクロールをやめて紙の幅に収め、行の途中で改ページしない。見出し行はページごとに繰り返す。
- 青色申告決算書は、画面で選んでいるページに関係なく4ページ全部を1枚ずつ印刷する（各ページに「青色申告決算書（一般用）nページ」の見出し）。控除額の選択欄と説明は印刷しない。
- 消費税の申告計算は、計算方法の選択欄と決算整理の仕訳の欄を印刷しない（使った方法は表の見出しに出る）。

## 確認状況

- 実施：`scripts/screenshots.cjs` で、帳票に印刷ボタンが出ること・帳票以外では出ないこと、印刷表示でタブが消え見出しが出ることを確認。Chromium で A4 の PDF を作り（`shots/*-print-*.pdf`）、青色申告決算書が4ページになることを確認した。
- 未確認：iPhone 実機の Safari・ホーム画面に追加した状態での印刷と PDF 保存（ホーム画面から起動したときに `window.print()` で印刷画面が開くか）。開かない場合は Safari で開いて共有メニューから印刷する。
- 総勘定元帳は科目の選択に「すべての科目（取引・残高のある科目）」を追加した（v0.11.0）。選ぶと全科目の元帳を科目順に続けて表示し、そのまま一括で印刷できる。出納帳は画面で選んでいる口座だけを印刷する（現金・預金の全口座は総勘定元帳の「すべての科目」で印刷できる）。

## CSV 出力（v0.11.0）

- 総勘定元帳：表示中の科目（「すべての科目」なら全科目）を CSV で書き出す。出納帳：表示中の口座・月を書き出す
- 列：コード・勘定科目・補助科目・日付・No.・相手科目・摘要・借方（出納帳は入金）・貸方（出納帳は出金）・残高。科目ごとに先頭へ繰越の行（前期繰越・前月繰越）を入れる
- 金額は `-1000` 形式、UTF-8（BOM 付き）。作成は `js/csv.js` の `ledgerCsv`（純粋関数、テストあり）
