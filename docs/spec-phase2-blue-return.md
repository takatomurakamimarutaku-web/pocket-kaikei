# 第2弾：青色申告決算書（一般用）の様式

個人事業主の帳簿から、国税庁の「青色申告決算書（一般用）」4ページの各欄を様式の並びで表示する。
確定申告書等作成コーナーや e-Tax に転記するための数字で、PDF の様式そのものを作るものではない（印刷/PDF は次の項目）。

画面：帳票 → 青色申告決算書（`#/reports/blue-return?page=1..4`）。法人では案内だけを出す。

## 1ページ目：損益計算書

| 欄 | 内容 | 計算 |
|---|---|---|
| ① | 売上（収入）金額（雑収入を含む） | 区分「売上」の科目＋雑収入 |
| ②〜⑦ | 売上原価 | ②期首棚卸 ③仕入 ④＝②＋③ ⑤期末棚卸 ⑥＝④－⑤ ⑦＝①－⑥ |
| ⑧〜㉔ | 経費（租税公課〜貸倒金） | 勘定科目テンプレートのコード 600〜616 で対応 |
| ㉕〜㉚ | 空欄の経費 | テンプレートにない経費科目（利用者が追加した科目）を金額のあるものから順に入れる。7つ目以降は㉛雑費に合算して注記 |
| ㉛ | 雑費 | コード 699 |
| ㉜ | 経費の計 | ⑧〜㉛ |
| ㉝ | 差引金額 | ⑦－㉜ |
| ㉞〜㊲ | 貸倒引当金等の繰戻額 | ㊲＝計 |
| ㊳〜㊷ | 専従者給与・貸倒引当金等の繰入額 | ㊷＝計 |
| ㊸ | 青色申告特別控除前の所得金額 | ㉝＋㊲－㊷ |
| ㊹ | 青色申告特別控除額 | min(選んだ控除額, max(0, ㊸)) |
| ㊺ | 所得金額 | ㊸－㊹ |

- ㊸ は損益計算書（`statements.js`）の所得と一致することをテストで確認している。
- 控除額の選択（65万・55万・10万・75万・適用しない）は会計期間に保存する（`period.blueReturn.deduction`）。
  - 令和9年分以後は75万円の区分が加わり、10万円の対象などが変わる（国税庁「青色申告特別控除の見直し」0026004-012.pdf）。
    55万円の扱いは未確認のため、画面では「国税庁の案内で確認」と注記している。

## 2ページ目：月別売上（収入）金額及び仕入金額・特別控除額の計算

- 月ごとの売上・仕入を表示する。雑収入は別の行にし、売上の合計が①、仕入の合計が③と一致する（テストあり）。
- 家事消費は仕訳で売上に計上していれば月別の金額に含まれる。
- 給料賃金・専従者給与・地代家賃・貸倒引当金の内訳は帳簿から作らない（作成コーナーで入力）。

## 3ページ目：減価償却費の計算

- 固定資産台帳から、取得価額・償却の基礎になる金額・償却方法・耐用年数・償却率（または改定償却率、一括償却は 1/3）・本年中の償却期間・本年分の償却費・事業専用割合・必要経費算入額・未償却残高を表示する。
- そのため `depreciationSchedule()` の各行に `base`（償却の基礎：定額法は取得価額、定率法は期首帳簿価額または改定取得価額）と `rate` を追加した。
- 必要経費算入額の計と 1ページ目の⑱減価償却費が違えば、減価償却の仕訳を確かめるよう注意を出す。

## 4ページ目：貸借対照表（資産負債調）

- 様式の科目の並び（現金〜土地・事業主貸、支払手形〜貸倒引当金・事業主借・元入金）で期首・期末を表示する。
- テンプレートにない科目（敷金など）は空欄の行に科目名を入れて表示する。帳簿の科目名が様式と違う場合は「帳簿の科目：…」と添える。
- 期末の負債・資本の部には「青色申告特別控除前の所得金額」（㊸）を入れる。期首・期末とも資産合計＝負債・資本合計であることをテストで確認し、画面にも表示する。

## 確認状況

- 実施：`test/blue-return.test.js`（損益の各欄・控除額・月別合計・減価償却の表・貸借一致）、スマホ幅のスクリーンショット（`shots/individual-42〜45-blue-return-*.png`）。
- 欄番号の照合（2026-10-29）：国税庁の書き方（037.pdf）で、経費が⑧〜㉛、⑧租税公課・⑱減価償却費・⑳給料賃金、繰戻額等が㉞〜㊱、専従者給与が㊳、繰入額等が㊴〜㊶、貸借対照表の所得金額が㊸と一致することを確認した。様式（令和7年分 10.pdf）で、経費18科目の並びと貸借対照表の科目の並び（現金〜土地・事業主貸、支払手形〜貸倒引当金・事業主借・元入金）がアプリと同じであることを確認した。
  - 確認の方法：PDF の文字を読み取って照合した。書き方の PDF は丸数字が別の記号に置き換わって抽出されたため、記号の並び（連番）から番号を読み取った（例：㊸に当たる記号から逆算して、専従者給与＝㊳、繰入額等＝㊴〜㊶）。様式の紙面を目で見て確かめてはいない。
  - 確認後もアプリの欄番号・並びに変更はなかった。
- 未対応：農業所得用の様式（不動産所得用は v0.39.0 で対応。spec-phase2-real-estate.md）、引当金・準備金の明細、地代家賃・利子割引料の内訳、PDF の様式そのものへの出力。
