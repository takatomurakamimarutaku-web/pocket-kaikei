## 判断と根拠

- **対応は令和8年分だけ**：令和9年分はひとり親控除の額と防衛特別所得税の扱いが変わる。国税庁の令和9年分の資料が出てから足す（一覧と入力画面に「対応していません」と出す）
- **申告書の内容は年分ごとに持つ**（従業員の登録には持たない）。確定した年の内容が後で変わらないようにするため。新しい年分は前の年の本人・配偶者・扶養親族を引き継ぐ（保険料・住宅ローン・前職分は毎年入れ直す）
- **扶養親族は1人ずつ生年月日と所得で区分する**（一般・特定扶養・老人・同居老親等・16歳未満・特定親族・対象外）。16歳未満も入れてもらう（障害者控除・23歳未満の判定・源泉徴収票に使う）
- **ほかの人の扶養控除の対象にしている子**：扶養控除・障害者控除には数えないが、23歳未満の扶養親族として生命保険料控除の特例と所得金額調整控除の判定には数える（夫婦の両方が適用できる：107.pdf、所得金額調整控除）
- **給与の集計**：支給日がその年の給与・賞与（仕訳を登録していないものも含め、警告を出す）。社会保険料は健康保険・厚生年金・雇用保険の本人負担。年末調整の過不足は含めない
- **確定**：その時点の結果を残す。確定した後に給与が変わると、一覧と入力画面に違いを出し、精算できないようにする（確定を取り消して計算し直す）
- **精算**：確定した過不足を、仕訳を登録していない同じ人の給与（その年か翌年1月に支給）の控除に入れる。給与の画面からは過不足を変えられない（年末調整の画面で付け外し）
  - 給与の仕訳：不足額は預り金（源泉所得税）の貸方を増やし、超過額（還付）は預り金の借方に入れる
  - 納付の集計：年末調整による不足税額・超過税額を足し引きし、引ききれない超過税額は後の納付から順に引く（年をまたいでも続ける）
- **年末調整をしない人**：乙欄の人、給与の収入金額が2,000万円を超える人、課税給与所得金額が18,050,000円を超える人は確定できない。年の中途で退職した人（在籍していない人）は注意を出すだけ（死亡退職などは対象のため）

## 画面

- 給与計算 › 年末調整（`#/payroll/year-end?year=2026`）：その年に給与を支払った人の状態（未入力・下書き・確定・精算済み）、年調年税額・過不足額、徴収・還付の合計、CSV
- 入力（`#/payroll/year-end/new?employee=…&year=…`・`#/payroll/year-end/:id`）：本人・配偶者・扶養親族・保険料・住宅ローン控除・前職分。入力に合わせて計算の結果（源泉徴収簿の年末調整の欄の並び）を出す。保存・保存して確定・削除
- 確定後：精算する給与を選んで精算・精算を外す・確定を取り消す
- 給与明細・給与の入力・給与の一覧：年末調整（還付・不足額の徴収）の行
- 納付：年末調整による不足税額・超過税額・前の納付で引ききれなかった超過税額・本税

## データ

- `DB_VERSION` 11：`yearEnds` ストア（`employeeId` の索引）。1人1年分に1件
  - `status`（draft・fixed・settled）、`person`・`spouse`・`dependents`・`insurance`・`housingLoan`・`previous`・`note`、`result`（確定した結果）・`fixedAt`・`settledPayrollId`
- 給与（payrolls）に `yearEndTax`（＋は徴収、−は還付）と `yearEndId`
- `BACKUP_VERSION` 11：旧形式は `yearEnds: []` を補う。給与と年末調整の参照・1人1年分を検証する

## 未確認の事項・対象外

- **令和9年分以降**：未対応（国税庁の資料が出てから）
- **非居住者の親族**：30歳以上70歳未満の国外居住親族の要件（留学・障害者・38万円以上の送金）は判定しない。対象になる人だけを入力してもらう
- **寡婦・ひとり親・勤労学生の要件**：所得の上限だけを確かめる（ほかの要件は申告書で確かめてもらう）
- **前職分の判定**：前職の源泉徴収票の金額をそのまま足す。年の途中で乙欄から甲欄に変わった人の扱いは利用者に任せる（警告を出す）
- **最後の給与の税額計算を省略する方法**：使わない。12月の給与も通常どおり計算し、年税額との差を精算する（どちらでも年税額は同じ）
- **不足額徴収の繰延べ**（不足額徴収繰延承認申請書）：未対応。差引支給額がマイナスになるときは保存できない
- **源泉徴収票・法定調書合計表・給与支払報告書**：次の PR
