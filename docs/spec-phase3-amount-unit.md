# 金額の表示単位（円・千円・百万円）

2026-10-29 たかとさんの依頼「画面・帳票ごとに、その場で金額単位を変えられると楽」（v0.55.0）。

## 決めたこと

| 項目 | 内容 | 理由 |
| --- | --- | --- |
| 単位 | 円・千円・百万円 | 会社計算規則の計算書類は「一円単位、千円単位又は百万円単位」、財務諸表等規則は「百万円単位又は千円単位」で表示する（下の出典） |
| 端数 | 既定は切り捨て。四捨五入も選べる | 有価証券報告書では「千円未満を切り捨てて表示」が一般的。どちらも実務にあるので選べるようにする |
| 換算の方法 | 整数の剰余だけで計算する（`money.js` の `toUnit`）。マイナスは絶対値で換算して△を付ける | 浮動小数点で計算しないルール。切り捨ては 0 の側へ、四捨五入は 0.5 を 0 から遠い側へ |
| 合計・小計 | 1円単位で計算した合計を、それぞれ換算する（内訳を換算してから足さない） | 帳簿の金額を変えずに済み、資産合計＝負債・純資産合計の表示も必ずそろう。代わりに内訳の和と合計が単位未満のずれで合わないことがある（有価証券報告書と同じ扱い）。差額をどこかの行に寄せる方法は、科目の金額が帳簿と食い違うので採らない |
| 単位未満のマイナス | 「△0」と表示する | 0 と区別して、マイナスであることを残す |
| 構成比・増減率 | 1円単位の金額で計算する | 換算後の数字で割ると、単位によって比率が変わってしまう |
| 対象の画面 | 残高試算表・月次推移試算表・月次推移表・部門別損益・損益計算書・貸借対照表・決算書（法人）・製造原価報告書・キャッシュフロー計算書・資金繰り表・予算と実績 | 集計の帳票。仕訳帳・元帳・出納帳・税金の申告書・青色申告決算書は1円単位で書くものなので対象外 |
| 覚え方 | 画面ごとに、アプリを開いている間だけ覚える。保存しない | 帳簿のデータではないため。開き直すと円に戻る |
| CSV | 1円単位のまま | 機械で読むデータのため |
| 確認の文 | 「資産合計 ○円 ＝ …」などの確認の文は1円単位のまま | 貸借の一致を確かめる文なので、丸めない |

## 印刷

- 試算表・損益計算書・貸借対照表（印刷条件のある帳票）：印刷条件に「金額の単位」「単位未満の端数」を足した。最初は画面で選んだ単位
- そのほかの帳票（画面の表から作る）：画面の表示のまま印刷し、右上の単位の欄に画面の単位を書く
- 右上の表記：「（単位：円）」「（単位：千円・千円未満切り捨て）」

## 仕組み

- `money.js`：`AMOUNT_UNITS`・`ROUNDINGS`・`toUnit`・`formatAmount`・`unitCaption`・`normalizeUnit`（純粋関数、`test/amount-unit.test.js`）
- `ui.js`：`amountCell` は今の表示単位（`setAmountUnit`）で整形する。`app.js` が画面を開くたびに円へ戻すので、単位の切替を置いた画面の中だけで効く
- `views/report-common.js`：`unitPicker`（切替の部品）と `unitPrintOptions`（印刷条件）
- `print-forms.js`：`trialBalanceDoc`・`statementDoc`・`balanceSheetAccountDoc` に `unit` を足した（既定は円で、出力は変わらない）

## 出典

- 会社計算規則 第57条第1項（計算関係書類の金額は一円単位、千円単位又は百万円単位で表示）、財務諸表等規則 第10条の3（百万円単位又は千円単位）。
