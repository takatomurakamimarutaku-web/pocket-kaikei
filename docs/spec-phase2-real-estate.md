# 青色申告決算書（不動産所得用）（個人・v0.39.0）

機能精査の C-4「個人の残り」の1つ目。たかとの指示「提案してくれたものは全部実装して」（2026-10-29）による。
対象は従来どおり個人事業主（青色申告）。アパート・駐車場などの貸付けがある人が、一般用と同じように決算書の各欄を転記できるようにする。

## 使い方

- 事業者の設定（個人だけ）の「不動産所得」を選ぶ：なし／事業と両方／不動産だけ（`settings.realEstate`。`none`・`both`・`only`）
- 「事業と両方」「不動産だけ」にすると、次の科目を追加する（`accounts.js` の `REAL_ESTATE`。製造原価と同じく、使っていなければ削除できる。「なし」に戻しても科目は残す）
  - 不動産収入（`re_income`）：550 賃貸料、551 礼金・権利金・更新料、552 名義書換料その他
  - 不動産経費（`re_expenses`）：650 租税公課（不動産）、651 損害保険料（不動産）、652 修繕費（不動産）、653 減価償却費（不動産）、
    654 借入金利子（不動産）、655 地代家賃（不動産）、656 給料賃金（不動産）、657 管理費（不動産）、658 支払手数料（不動産）、669 その他の経費（不動産）
  - 専従者給与（不動産）（`re_family_salary`）：730
  - 負債：306 預り敷金・保証金
- コードが使われていれば空いている次の番号にする。欄の割り当ては目印（hint）で行い、科目名では判定しない
- 税区分の初期値：賃貸料・礼金等は非課税売上、名義書換料その他は課税売上10%。店舗・事務所の部分や家賃と別に受け取る駐車場使用料は課税なので、仕訳で税区分を変える
- 帳票メニューに「青色申告決算書（不動産所得用）」を出す。「不動産だけ」のときは一般用を出さない
- 固定資産：償却費の科目に「減価償却費（不動産）」を選べる（「不動産だけ」なら新しい資産の初期値にする）。その資産は不動産所得用の3ページに載り、一般用には載らない

## 1ページ目：損益計算書（`real-estate.js` の `realEstateIncomeStatement`）

| 欄 | 内容 |
|---|---|
| ① 賃貸料 | 目印 `re_rent_income` |
| ② 礼金・権利金・更新料 | 目印 `re_key_money` |
| ③ 名義書換料その他 | 目印 `re_other_income` と、目印の無い不動産収入の科目 |
| ④ 計 | ①＋②＋③ |
| ⑤〜⑪ | 租税公課・損害保険料・修繕費・減価償却費・借入金利子・地代家賃・給料賃金（それぞれの目印） |
| ⑫〜⑯ | 目印の無い不動産経費の科目（金額のあるもの）。入りきらない分は⑰に含める |
| ⑰ その他の経費 | 目印 `re_misc` ＋ 入りきらない分 |
| ⑱ 計 | ⑤〜⑰ |
| ⑲ 差引金額 | ④−⑱ |
| ⑳ 専従者給与 | 区分 `re_family_salary` |
| ㉑ 青色申告特別控除前の所得金額 | ⑲−⑳ |
| ㉒ 青色申告特別控除額 | 下の「控除の配分」 |
| ㉓ 所得金額 | ㉑−㉒ |

- 一般用（`blueIncomeStatement`）は区分 `sales`・`sga` などで集計するので、不動産所得の区分は自動的に入らない
- ㉓が赤字のときは「土地等を取得するために要した負債の利子の額」を入れる欄を出す（期間の `blueReturn.landInterest`）

## 青色申告特別控除の配分（`blueReturnSet`・`allocateBlueDeduction`）

- 控除額は不動産所得の金額、事業所得の金額から順に差し引く（どちらも所得金額が限度）
  - ㉒＝min(選んだ控除額, ㉑)（㉑が赤字なら0）
  - 一般用の㊹＝min(選んだ控除額−㉒, ㊸)
- 控除額の選択は一般用と共通（期間の `blueReturn.deduction`）。どちらの画面で選んでも同じ値
- 貸付けの規模（期間の `blueReturn.scale`：`business` 事業的規模／`small` 事業的規模でない。既定は事業的規模でない）
  - 「不動産だけ」で事業的規模でない → 控除の選択肢は10万円・適用しないだけ（`deductionLimited`）
  - 事業所得があれば、事業的規模でない不動産所得からも55万円・65万円の控除を先に引ける
  - 事業的規模でないのに専従者給与（不動産）があれば、必要経費にならないことを知らせ、事業主貸に直すよう案内する（金額は帳簿のまま。貸借対照表と合わせるため）

## 2〜4ページ目

- 2ページ：不動産所得の収入の内訳（賃借人ごと）。賃貸料・礼金等の科目の補助科目を賃借人として、名前でまとめる。計が④と一致するかを表示する。
  給料賃金・専従者給与の内訳（補助科目ごと）。青色申告特別控除額の計算（㉑・選んだ控除額・㉒・一般用の㊹）
  - 貸家・貸地等の別、用途、住所、貸付面積、契約期間、月額、保証金・敷金、源泉徴収税額は帳簿から作らない（作成コーナーで入力）
- 3ページ：減価償却費の計算（償却費の科目が不動産経費の資産）。必要経費算入額の計と⑧が違えば知らせる。地代家賃・借入金利子の内訳（補助科目ごと）
- 4ページ
  - 「事業と両方」：貸借対照表は両方の所得の資産・負債を合算して一般用の4ページに書く。一般用の「青色申告特別控除前の所得金額」は㊸＋㉑
  - 「不動産だけ」：この決算書に書く。科目は帳簿の科目名で、金額のある行だけ出す

## 確定申告書・ほかの画面

- 第一表：収入金額等 ㋒不動産＝④、所得金額等 ③不動産＝㉓。㉓が赤字のときは、赤字が土地等の負債利子以下なら0、超えれば差額（`realEstateForFirstTable`）。
  ⑫合計は①＋③＋⑥＋⑩＋⑪（事業所得・不動産所得の赤字は損益通算する）
- 専従者給与（控除）額の合計額＝㊳＋⑳、青色申告特別控除額＝㊹＋㉒
- 損益計算書（帳票）：不動産所得の科目があれば「事業所得（青色申告特別控除前）」「不動産収入」「不動産経費」「専従者給与（不動産）」「不動産所得」を分けて出す。
  `netIncome`（貸借対照表・繰越に使う）は両方の合計。`profits.businessIncome`・`profits.realEstateIncome` を加えた
- 経営分析（個人）は事業所得で計算する（不動産収入は売上に入らないため）
- 個人事業税の見込みは事業所得だけで計算する（不動産貸付業が事業税の対象になるかは都道府県の認定基準によるため）
- 資金繰り表：不動産収入は売上の入金、不動産経費・専従者給与（不動産）は経費の支払、租税公課（不動産）は税金の支払。減価償却費（不動産）は資金の動きに入れない
- 家事按分：不動産経費（減価償却費を除く）にも事業割合を設定できる

## 出典（2026-10-29 確認）

- 国税庁「令和7年分 青色申告決算書（不動産所得用）の書き方」 https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/039.pdf
  - 専従者の給与は⑪ではなく⑳に書く。⑫〜⑯は⑤〜⑪に当てはまらない費目
  - 「事業所得がなく、不動産所得のある方の貸借対照表はこの表に記入します」。貸借対照表の「青色申告特別控除前の所得金額」は㉑
  - ㉓が赤字で必要経費に土地等を取得するために要した負債の利子があるときはその額を書き、第一表の「不動産③」は、赤字が利子の額以下なら0、利子の額より大きければ差額（△）
  - 事業的規模でない不動産の貸付けは、ほかに事業所得がある場合を除き、55万円（65万円）の控除は受けられない
- 国税庁「令和7年分 青色申告決算書（一般用）の書き方」 https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/037.pdf
  - 「農業所得以外の事業所得のほかに農業所得や不動産所得のある方の貸借対照表は、それらの所得に係るものを合算してこの表に記入しますが、それぞれの貸借対照表を各別に記入しても差し支えありません」
- 国税庁 タックスアンサー No.2072 青色申告特別控除 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2072.htm
  - 55万円・65万円の要件「不動産所得または事業所得を生ずべき事業を営んでいること」。控除額は「不動産所得の金額、事業所得の金額から順次控除します」。所得金額の合計額が限度
- 国税庁 タックスアンサー No.1373 事業としての不動産貸付けとそれ以外の不動産貸付けとの区分 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1373.htm
  - 貸間・アパート等はおおむね10室以上、独立家屋はおおむね5棟以上（5棟10室基準）
- 国税庁 タックスアンサー No.6226 住宅の貸付け https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6226.htm
  - 家賃には返還しない敷金・保証金・一時金等と共益費を含む（非課税）。家賃と別に受け取る駐車場使用料、店舗部分は非課税にならない
- 参考（集計の仕方）：マネーフォワード クラウド確定申告「決算書（不動産所得用）の逆引き」 https://biz.moneyforward.com/support/tax-return/tax-return-guide/bs2/kessansho-gyakubiki-2023-02.html
  （事業所得と不動産所得の貸借対照表は合算した金額を反映）

## 未確認・推測

- 合算した貸借対照表（一般用）の「青色申告特別控除前の所得金額」を㊸＋㉑にした（書き方は「㊸を記入」だが、合算すると㊸だけでは貸借が一致しないため。推測）
- 不動産所得用の貸借対照表の科目の行の並びは確認できなかった（様式の PDF の文字が読めない）。帳簿の科目名で出している
- 更新料の消費税：No.6226 に明記は無い。住宅の貸付けで返還しない一時金に当たると考えて非課税売上を初期値にした（推測。仕訳で変えられる）
- ⑲の欄名「差引金額」と、2ページ目の「青色申告特別控除額の計算」の欄番号は確認できなかったので、番号を付けずに出している

## 対応していないもの

- 特定組合員等の不動産所得の損失（⑲を0にする場合）
- 不動産所得の貸倒引当金（個別評価）
- 個人事業税の不動産貸付業（第1種事業）の計算（事業所得と税率が違うことがあるため、見込みには含めない）
- 損失の繰越し（第四表）は C-4 の2つ目で作る
