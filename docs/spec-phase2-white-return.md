# 収支内訳書（白色申告）と確定申告書 第四表（損失申告用）（個人・v0.40.0）

機能精査の C-4「個人の残り」の2つ目。たかとの指示「提案してくれたものは全部実装して」（2026-10-29）による。
CLAUDE.md の対象は「個人事業主（青色申告）と法人」。白色申告はこの対象を広げるもので、機能精査の提案（C-4）に含めて承認を受けている。

## 使い方

- 事業者の設定（個人だけ）の「申告の種類」を選ぶ：青色申告／白色申告（`settings.filing`。`blue`・`white`。無いデータは青色）
  - 初期設定では選ばない（最初は青色申告）。「事業の形態」の呼び名を「個人事業主（青色申告）」から「個人事業主」に変えた
  - 法人は白色にできない（`updateSettings` とバックアップの検証で拒否）
- 白色申告にすると、帳票メニューの「青色申告決算書」「青色申告決算書（不動産所得用）」の代わりに「収支内訳書」を出す。青色の画面を直接開いたときは案内を出す
- 損益計算書・貸借対照表・資金繰り・経営分析・事業税の画面では、所得金額の呼び名を「青色申告特別控除前」から「専従者控除前」にする（`statements.js` の `incomeBeforeLabel`）
- 勘定科目・仕訳・帳簿は青色と同じ。白色申告でも複式簿記で記帳してかまわない

## 収支内訳書（一般用）（`white-return.js` の `whiteIncomeStatement`）

| 欄 | 内容 |
|---|---|
| ① 売上（収入）金額 | 区分 `sales` のうち、テンプレートの雑収入（501）以外 |
| ② 家事消費 | 0（帳簿では区別できない。売上の科目で記帳していれば①に入る） |
| ③ その他の収入 | テンプレートの雑収入（501） |
| ④ 計 | ①＋②＋③ |
| ⑤ 期首商品（製品）棚卸高・⑥ 仕入金額・⑧ 期末商品（製品）棚卸高 | 青色申告決算書と同じく役割（`opening_inventory`・`closing_inventory`）で分ける |
| ⑦ 小計・⑨ 差引原価・⑩ 差引金額 | ⑤＋⑥、⑦−⑧、④−⑨ |
| ⑪〜⑯ | 給料賃金（612）・外注工賃（613）・減価償却費（610）・貸倒金（616）・地代家賃（615）・利子割引料（614） |
| その他の経費 | ㋑租税公課（600）㋺荷造運賃（601）㋩水道光熱費（602）㋥旅費交通費（603）㋭通信費（604）㋬広告宣伝費（605）㋣接待交際費（606）㋠損害保険料（607）㋷修繕費（608）㋦消耗品費（609）㋸福利厚生費（611） |
| ㋾㋻㋕㋵㋟（空欄の行） | 上に当てはまらない経費の科目（金額のあるもの）。入りきらない分は㋹に含める |
| ㋹ 雑費 | 雑費（699）＋入りきらない分 |
| ⑰ | その他の経費の計 |
| ⑱ | ⑪〜⑯＋⑰ |
| ⑲ 専従者控除前の所得金額 | ⑩−⑱ |
| ⑳ 専従者控除 | 下の「事業専従者控除」 |
| ㉑ 所得金額 | ⑲−⑳ |

- 括弧の数字はテンプレートの科目コード。科目名では判定しない
- 帳簿の専従者給与（`family_salary`）は白色申告では必要経費にならないので含めず、事業主貸に直すよう知らせる
- 貸倒引当金の繰入額・繰戻額（`reserves_*`）は様式に欄が無いので含めず、知らせる（一括評価は青色申告者だけ）
- 確認：⑲は青色申告決算書（一般用）の㉝差引金額と同じ（テストで確認）
- 2ページ：売上（収入）金額の明細・仕入金額の明細（補助科目ごと）、減価償却費の計算（不動産所得の資産を除く）、地代家賃・利子割引料・給料賃金の内訳（補助科目ごと）。
  登録番号・所在地、給料賃金の年齢・従事月数・源泉徴収税額、税理士等の報酬は作成コーナーで入力

## 収支内訳書（不動産所得用）（`whiteRealEstateStatement`）

青色申告決算書（不動産所得用）と同じ目印で集計し、白色の様式の欄に並べ替える。

| 欄 | 内容 |
|---|---|
| 収入金額 | 賃貸料（`re_rent_income`）・礼金・権利金・更新料（`re_key_money`）・名義書換料・その他（そのほかの不動産収入）と計 |
| ⑥ 給料賃金・⑦ 減価償却費・⑨ 地代家賃・⑩ 借入金利子 | 目印 `re_wages`・`re_depreciation`・`re_rent`・`re_interest` |
| ⑧ 貸倒金 | 0（目印が無い。不動産の貸倒れの科目は空欄の行に入る） |
| その他の経費 | ㋑租税公課（`re_taxes`）㋺損害保険料（`re_insurance`）㋩修繕費（`re_repairs`）㋥空欄（目印の無い科目の1つ目）㋭雑費（`re_misc`＋入りきらない科目） |
| ⑪・⑫ | その他の経費の計、⑥〜⑩＋⑪ |
| ⑬ 差引金額 | 収入金額の計−⑫ |
| ⑭ 専従者控除 | 事業として行う貸付け（事業的規模）だけ |
| ⑮ 所得金額 | ⑬−⑭。赤字で土地等を取得するための負債の利子があれば、第一表の不動産③は青色と同じ扱い（`realEstateForFirstTable`） |

- 確認：⑬は青色申告決算書（不動産所得用）の⑲と同じ（テストで確認）
- 2ページ：収入の内訳（賃借人＝補助科目ごと）、減価償却費の計算（不動産経費の資産）、借入金利子・地代家賃・給料賃金の内訳

## 事業専従者控除（`familyWorkerDeductions`・`whiteReturnSet`）

- 1人ごとに min(86万円（配偶者）・50万円（配偶者以外）, 事業所得等の金額 ÷（専従者の数＋1））。割り算の1円未満は切り捨て。事業所得等の金額が0以下なら0
- 事業所得等の金額＝一般用の⑲＋（事業的規模なら）不動産所得用の⑬
- 専従者は収支内訳書の画面で入力する（氏名・配偶者か・従事する事業）。期間の `whiteReturn = { workers: [{ name, spouse, work }], scale, landInterest }`。配偶者は1人まで、10人まで。締めた期間は保存できない
  - 従事する事業：事業所得と事業的規模の不動産所得の両方があるときだけ選べる。一般用が無ければ不動産所得、貸付けが事業的規模でなければ事業所得にする
  - 不動産所得だけで事業的規模でないときは控除できない（知らせる）
- 専従者は配偶者控除・扶養控除の対象にならない。確定申告書の配偶者・親族の入力に「事業専従者」の印を付けると控除から外す（青色事業専従者も同じ）

## 確定申告書（白色申告のとき）

- 第一表 ㋐＝一般用の④、①＝一般用の㉑、㋒＝不動産所得用の収入金額の計、③＝不動産所得用の⑮（土地等の負債利子の扱いは青色と同じ）
- 「専従者給与（控除）額の合計額」＝専従者控除の合計。青色申告特別控除額の行は出さない
- 添付書類：収支内訳書（一般用・不動産所得用）

## 第四表（損失申告用）（`income-tax.js` の `computeIncomeTax` の `loss`）

- 1・2：経常所得（①〜⑥・⑩。事業・不動産・給与・雑所得を損益通算した後）。マイナスなら本年分の純損失
- 3：翌年以後に繰り越す損失額。青色申告は純損失の全額（青色申告者の損失の金額）、白色申告は0（変動所得・被災事業用資産の損失は計算しない）
- 4：繰越損失を差し引く計算。確定申告書の入力に「繰越損失（第四表）」（3年前・2年前・前年の分の、前年分までに引ききれなかった純損失）を入れる（`incomeTaxReturn.lossCarry = { y3, y2, y1 }`）
  - 古い年分から、合計所得金額の範囲で差し引く。Ⓐ前年分までに引ききれなかった損失額、Ⓑ本年分で差し引く損失額、Ⓒ翌年分以後に繰り越して差し引かれる損失額（Ⓐ−Ⓑ）
  - 3年前の分のⒸは翌年に繰り越せない（繰越期限切れと表示）
  - 来年の入力（3年前＝今年の2年前の残り、2年前＝今年の前年の残り、前年＝本年の純損失（青色だけ））を表示する
- 所得の使い分け
  - 合計所得金額（繰越控除の前）：基礎控除・配偶者控除・寡婦・ひとり親・勤労学生の所得要件
  - 総所得金額等（繰越控除の後。第四表の M。第一表の⑫）：医療費控除の足切り（5%）・寄附金控除の上限（40%）・課税される所得金額
- 純損失がある年か、繰越損失を入力した年に第四表の欄を出し、添付書類にも出す

## 出典（2026-10-29 確認）

- 国税庁「令和7年分 収支内訳書（一般用）の書き方」 https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/034.pdf
  - 経費⑪〜⑯とその他の経費（㋑〜㋸・㋹雑費）の欄名、家事消費・その他の収入の書き方
  - 事業専従者控除：(1) 86万円（配偶者以外は50万円）、(2)「⑲の金額÷（事業専従者数＋1）」の少ない方。専従者は生計を一にする配偶者・15歳以上の親族で6か月を超えて専ら従事した人
  - 2ページ：売上（収入）金額の明細・仕入金額の明細・減価償却費の計算・地代家賃の内訳・利子割引料の内訳・給料賃金の内訳・税理士等の報酬
- 国税庁「令和7年分 収支内訳書（不動産所得用）の書き方」 https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/019.pdf
  - ⑥給料賃金・⑦減価償却費・⑧貸倒金・⑨地代家賃・⑩借入金利子、㋑租税公課・㋺損害保険料・㋩修繕費・㋭雑費
  - ⑮が赤字で土地等を取得するための負債の利子があるときの第一表「不動産③」の書き方
  - 不動産の貸付けが事業として行われていないときは専従者控除を適用できない
- 国税庁 タックスアンサー No.2075 青色事業専従者給与と事業専従者控除 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2075.htm
  - 控除額は「配偶者86万円、配偶者でなければ50万円」と「この控除をする前の事業所得等の金額を事業専従者の数に1を足した数で割った金額」の低い方
  - 事業専従者は同一生計配偶者・扶養親族になれない
- 国税庁「令和7年分 確定申告書の書き方（損失申告用）」 https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/003.pdf
  - 第四表の区分（1 損失額又は所得金額、2 損益の通算、3 翌年以後に繰り越す損失額、4 繰越損失を差し引く計算（Ⓐ・Ⓑ・Ⓒ）、M）
  - 白色申告者が繰り越せるのは変動所得の損失・被災事業用資産の損失（と雑損失）だけ
  - 雑損控除・医療費控除・寄附金控除は第四表の M（繰越損失を差し引いた後）で計算する
- 国税庁 タックスアンサー No.2070 純損失の繰越控除と繰戻還付 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2070.htm（青色申告は翌年以後3年間繰越控除）
- 国税庁「専門用語の解説」 https://www.nta.go.jp/taxes/shiraberu/taxanswer/yogo/senmon.htm（合計所得金額は繰越控除の前、総所得金額等は後）

## 未確認・推測

- 一般用の②〜⑩・⑰・⑱・⑳の欄番号と欄名は書き方に番号付きで出てこないため、様式の並び（①〜㉑）から当てはめた（推測）
- 不動産所得用の収入金額の欄番号（①〜⑤）と⑪・⑫・⑭の欄名は確認できなかった。収入金額は番号を付けずに出し、⑪その他の経費の計・⑫必要経費の計・⑭専従者控除は⑥〜⑩・⑬・⑮の並びから当てはめた（推測）
- 事業所得と事業的規模の不動産所得の両方があるとき、専従者控除の「事業所得等の金額」を両方の合計にした。所得税法第57条第3項の「事業に係る不動産所得の金額、事業所得の金額又は山林所得の金額の合計額」による（条文の本文はこの環境で取得できず、記憶による。税務署で確認を勧める）
- 第一表の⑫は、第四表を使う年は繰越損失を差し引いた後の金額を出している。手引きでは第四表を使う場合の⑪・⑫の書き方が別に決まっている（損失申告の手引きに従うよう画面で案内）
- 専従者控除の割り算の1円未満は切り捨てにした

## 対応していないもの

- 白色申告の変動所得の損失・被災事業用資産の損失の繰越し、雑損控除と雑損失の繰越し、純損失の繰戻し還付（青色）
- 譲渡・一時・山林・退職所得、分離課税の所得がある場合の損益通算（第四表の B〜F 列）
- 前年の確定申告書からの繰越損失の自動読込み（来年の入力額を画面に出すので、手で入れる）
- 個人事業税の事業専従者控除（事業税の画面の「損失の繰越控除など」に含めて入れる）
- 期間ごとの申告の種類（設定は事業者に1つ。青色申告の承認を受けた年から切り替える場合は、前の年の帳票を見るときに設定を戻す）
