# 経営サポート 第1弾：着地見込みと納税予測（v0.73.0）

2026-10-31 たかとの依頼「管理会計でも使えるように。月次推移で決算予測→節税・税制の提案」。検討案（Claude Doc「決算予測と節税提案（経営サポート）の検討案」）で、Pocket会計の中に「会計｜経営」で切り替える独立した区画を作る形（C案）に決定。第1弾は着地見込みと納税予測。

## 構成

- 計算は `js/advisor/` の純粋関数（帳簿のデータを受け取るだけ）。後で別ソフトに切り出すときは、このフォルダとバックアップの読み込みで足りるようにする
  - `forecast.js`：着地見込み（`forecastLanding`）
  - `tax-forecast.js`：納税予測（`forecastTaxes`）
- 画面：`#/advisor`（経営のホーム）・`#/advisor/forecast`（着地見込み）・`#/advisor/tax`（納税予測）。会計のホームと経営のホームの上に「会計｜経営」の切替。PC のサイドメニューにも「経営サポート」
- 保存：見込みの立て方と手入力の金額だけを `period.forecast`（`{ actualThrough, methods, manual }`）に `Repository.saveForecast` で保存。DB・バックアップの版は変えない（期間のレコードの任意の項目。法人税の条件 `period.corporateTax` と同じ扱い）

## 着地見込みの計算

着地＝実績（実績とみなす最後の月まで）＋残りの月の見込み＋決算整理の見込み

- 実績とみなす最後の月：既定は今日の前月（当月は記帳の途中が多いため）。期間が終わっていれば最後の月
- 見込みの月にある仕訳（先日付の予定など）は着地に入れず、見込みに置き換える。決算整理の仕訳（`isAdjusting`）は残す
- 対象の科目：損益の科目（評価勘定・無効の科目・法人税等を除く）
- 見込みの立て方（科目ごと）
  - おまかせ：予算があれば予算 → 前期の帳簿があれば前期×伸び率 → 直近3か月の平均
  - 予算：予算の月別の金額
  - 前期の同じ月×伸び率：同じ暦の月の前期の発生額×伸び率。伸び率＝当期の実績の累計÷前期の同じ月までの累計（‰の整数、50%〜200%に収める、どちらかが0以下なら100%）。1円未満は四捨五入
  - 直近3か月の平均：実績の最後の3か月（決算整理を除く）。1円未満は四捨五入
  - 金額を入れる：残りの月の合計を均等に割る（端数は最後の月。予算の入力と同じ `spreadAnnual`）
  - 見込まない：0円
- 減価償却：期中に減価償却の仕訳（`source: 'depreciation'`）が無ければ、固定資産台帳の当期の償却額（事業分）から計上済みの額を引いて最後の月に見込む
- 期末棚卸：決算整理の仕訳が無ければ期首と同じと見なす（売上原価＝仕入）
- 見込みは「予測の仕訳」（相手科目は現金、税区分は科目の既定）にして実績の仕訳に足し、損益計算書・税額は既存の関数で計算する。予測の仕訳は保存しない

## 納税予測の計算

- 消費税（課税事業者）：`computeTaxReturn` に着地の仕訳と消費税の申告計算の設定（`period.taxReturn`）を渡す。決算整理の消費税等の仕訳が無ければ、納める額を租税公課として利益から引く（税込経理の前提。`consumptionTaxLines`）。計算方法ごとの税額（一般・簡易・2割・3割）も並べる
- 法人：`corporateTaxReturn`（法人税・地方法人税・防衛特別法人税・住民税・事業税）。条件は法人税の申告の画面の入力
- 個人：`computeIncomeTax`（所得税及び復興特別所得税。所得控除・予定納税は確定申告書の入力）と `individualEnterpriseTax`（個人事業税）。住民税はまだ計算しない（画面で案内）
- 納期限：法人は事業年度終了の日の翌日から2か月（`filingDeadline`）、個人の所得税は翌年3月15日、消費税は翌年3月31日（休日は翌日。`taxDueDate`）、個人事業税は8月（都道府県で違う）

税率・控除の出典は、それぞれの申告の画面の仕様書（spec-phase2-corporate-tax.md・spec-phase2-income-tax.md・spec-phase2-local-taxes.md・spec-phase2-tax-return.md）。2割特例・3割特例の案内文は国税庁「令和8年度税制改正特集」（https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice-review/index.htm 、2026-10-31 確認）。
