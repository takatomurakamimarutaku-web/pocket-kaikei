# 残高試算表・決算書の様式（v0.59.0、前期と比べる表・表紙は v0.61.0）

たかとさんの依頼（2026-10-30）：「残高試算表や決算書（貸借対照表や損益計算書）が見づらい。他の会計ソフトを参考にして見やすく、税務申告に添付できるものにする。科目と残高の間が空きすぎているなどはもってのほか。製品化を念頭に帳票様式のクオリティーを上げる」「ただ数字や情報を羅列すればいいわけではない」。

## 何が問題だったか

- 画面の表が画面の幅いっぱいに広がり、PC では科目と金額が大きく離れた。金額の列は1つだけで、区分の合計と科目の金額が同じ列に並んだ
- 印刷は、余った幅をすべて科目の列に回していた（表が用紙の幅いっぱいになり、科目と金額の間が空く）
- 損益計算書の段階利益の名前・純資産の部の区分が、会社法の計算書類の表示になっていなかった
- 残高試算表は科目を区分ごとに並べるだけで、利益の段階（売上総利益など）が分からなかった。スマホでは列が多く横にはみ出した

## 参考にしたもの

- 市販の会計ソフトの決算書の構成（表紙・貸借対照表・損益計算書・販売費及び一般管理費内訳書・製造原価報告書・株主資本等変動計算書・個別注記表）：[弥生会計 決算書](https://support.yayoi-kk.co.jp/product/account/kessansho_c.html)
- 損益計算書の配置（科目｜内訳の列｜合計の列、区分の合計は区分の最後の科目と同じ行の右の列、段階利益は右の列）：[ゆうちょ銀行 損益計算書の様式例](https://www.jp-bank.japanpost.jp/kaisetu/pdf/soneki_keisansho.pdf)
- 会社計算規則（[e-Gov 法令検索](https://laws.e-gov.go.jp/law/418M60000010013)）
  - 第76条：貸借対照表の純資産の部の区分（株主資本 › 資本金・資本剰余金・利益剰余金。利益剰余金は利益準備金・その他利益剰余金）
  - 第89条〜第94条：損益計算書の段階利益の表示（売上総利益金額・営業利益金額・経常利益金額・税引前当期純利益金額・当期純利益金額）。零未満のときは「売上総損失金額」などとし、零から差し引いた額（正の数）で表示する

公開資料に用紙の寸法などの細かな仕様は無いため、文字の大きさ・行の高さ・表の幅は、市販の決算書の印字例の見た目に合わせて決めた（推測を含む）。

## 決算書の表示の行（`js/fs-rows.js`、画面と印刷で共通）

損益計算書・貸借対照表・製造原価報告書を「表示の行」（`{ kind, label, level, inner, outer, rule }`）にする純粋関数。画面（`js/views/fs-view.js`）と印刷（`js/print-forms.js`）は同じ行を描く。

### 損益計算書・製造原価報告書（報告式）

- 金額は2列。科目の金額は左（内訳）の列、区分の合計は区分の最後の科目と同じ行の右の列
- 区分の科目が1つだけなら、その金額を右の列だけに書く（内訳と合計が同じ額になるため）
- 段階利益は右の列に、上に線。最後の行（当期純利益金額・青色申告特別控除前の所得金額・当期製品製造原価）は二重線
- 法人の段階利益は会社計算規則の名前（売上総利益金額など）。損失は「営業損失金額」のように書き、金額は正の数
- 売上原価・材料費に期末の棚卸高（評価勘定）があれば、その前に「合計」（個人は「小計」）の行を入れ、期末の棚卸高は差し引く金額として正の数で書く
- 法人税等は見出しを付けず、「法人税、住民税及び事業税」の行だけを書く
- 製造原価報告書の「合計」（当期総製造費用＋期首仕掛品棚卸高）は、期首仕掛品が無く当期総製造費用と同じ額になるときは省く

### 貸借対照表

- 勘定式（左に資産の部、右に負債の部・純資産の部）と報告式（上下）
- 区分の合計は区分の見出しの行の右に書き、科目は左の列（勘定式では1列にまとめて書く）
- 法人の純資産の部：株主資本 › 資本金・資本剰余金・利益剰余金（利益準備金・その他利益剰余金 › 繰越利益剰余金）。科目の区分は role・目印（hint）で判定する（名前では判定しない）
- 最後の行で資産合計と負債・純資産合計（個人は負債・資本合計）をそろえ、二重線を引く
- 個人の事業主貸は見出しを付けずに科目を書く（青色申告決算書の貸借対照表の並び）

## 画面

- 決算書は「用紙」（白い紙）の中に、中央の表題（字間を空け二重下線）・期間（貸借対照表は「…現在」）・左に事業者名・右に単位を置く
- 損益計算書は PC で幅 660px に収め、中央に置く（科目と金額を離しすぎない）
- 貸借対照表は PC で左右に並べ、中央に縦の線。スマホでは上下に並べる
- 決算書（法人）の画面の6つの帳票も同じ見た目にした。株主資本等変動計算書は見出しを2段（当期変動額の下に当期純利益・その他の変動）にし、スマホでは横にスクロールする

## 印刷（`js/print-layout.js` の追加）

- 表ごとの幅（`width`、mm）を持たせ、用紙の中央に置く。損益計算書は A4縦で 144mm（科目｜34mm｜34mm）、勘定式の貸借対照表は左右を同じ幅（93mm ずつ）にする（科目の名前の長さで片側だけ広がらないように）
- 表ごとの文字の大きさ・行の高さ（`font`・`headFont`・`rowH`・`headH`）。決算書は 9.5pt・5.9mm（試算表・元帳の 8pt より大きく、行の間を空ける）
- 決算書の体裁（`formal: true`）：作成日とアプリ名を出さず、表の左上に事業者名、右上に単位（表の幅にそろえる）。ページ番号は2ページ以上のときだけ「- n -」
- 決算書を1冊にする印刷（`financialStatementsDoc`）：帳票ごとに改ページし、各ページに表題と期間を出す。印刷条件で帳票を選べる。個別注記表のページは単位を書かない（見出しの `unit: ''`）
- 幅や文字の指定が無い表（仕訳帳・元帳・申告書など）は従来どおり

## 残高試算表（`js/trial-rows.js`、画面と印刷で共通）

市販の会計ソフトの残高試算表と同じく、貸借対照表・損益計算書・製造原価の科目に分けて、決算書と同じ順に並べる。

- 貸借対照表の科目：区分ごとに科目と区分の合計、部（資産・負債・純資産）の合計。部に区分が1つだけなら区分の合計は部の合計と同じ額になり、科目が1つだけの区分は科目と同じ額になるので省く
- 損益計算書の科目：損益計算書（`incomeStatement`）の区分の順に並べ、段階利益の行を入れる。期の途中でも見るので、法人は「売上総損益金額〜当期純損益金額」（損益。マイナスは△）と書く。個人は差引金額・青色申告特別控除前の所得金額（白色申告は専従者控除前）
  - 段階利益は決算書と同じ計算なので、決算の整理（棚卸など）が済んでいれば損益計算書の額と一致する
- 製造原価の科目（法人で製造原価の科目があるとき）：材料費・労務費・製造経費・当期総製造費用・仕掛品棚卸高・当期製品製造原価。損益計算書の科目の売上原価には「当期製品製造原価」の行（残高だけ）を入れる
- 合計残高試算表の印刷では、段階利益は利益を貸方残高、損失を借方残高の欄に正の数で書く。売上原価の中の当期製品製造原価は借方合計・借方残高の欄に書き、区分の合計に足す
- 最後に「全科目の合計」（借方合計＝貸方合計・借方残高＝貸方残高）を別の表で出す（段階利益の行と続かないように）
- スマホの画面では科目・繰越・残高の列だけを出し、「借方・貸方の列も表示」で切り替える
- CSV は機械で読むため、これまでどおり科目の一覧のまま（段階利益の行は入れない）

## 前期と比べる表（v0.61.0、`js/compare.js` の `compareIncomeRows`・`compareBalanceRows`）

損益計算書・貸借対照表の「前期と比べる」を、決算書と同じ並び・名前の「比較損益計算書」「比較貸借対照表」にした（それまでは区分ごとの表を並べるだけで、決算書と見た目が違った）。

- 決算書の表示の行（`fs-rows.js`）を当期・前期それぞれ作り、行の目印（科目は科目の id、段階利益は元の名前、そのほかは種類と名前）で突き合わせる。並びは当期のまま、前期にしか無い行は前期の並びで直前の行の後に入れる
- 金額は期ごとに1列（科目｜当期｜前期｜増減額｜増減率）。損益計算書の区分の合計（決算書では右の列）は「〇〇合計」の行に分ける（個人の売上原価は青色申告決算書にならい「差引原価」）。科目が1つだけの区分は、科目と同じ額になるので合計の行を作らない
- 売上原価は決算書と同じく「合計」の行を入れ、期末の棚卸高は差し引く額として正の数で書く
- 法人の段階利益は「売上総損益金額」〜「当期純損益金額」（当期と前期で利益・損失が分かれても同じ行に並べるため。残高試算表と同じ名前。マイナスは△）
- 増減率は前期の絶対値で割る（これまでどおり）。前期が0のとき、利益と損失（プラスとマイナス）が入れ替わったときは意味を持たないので「—」にする（推測を含む判断：市販ソフトの表示を確かめたものではない）
- 比較貸借対照表は報告式（資産の部・資産合計・負債の部・純資産の部・負債純資産合計）。前期末は当期の期首残高（前期末の残高を繰り越したもの）。区分の合計は区分の見出しの行に書く（決算書の貸借対照表と同じ）。前期の「うち当期純利益」は比べない
- 0円の行は、当期・前期のどちらかで決算書に出る行を出す（0円の科目も出すときはすべて）
- 画面：表題は「比較損益計算書」「比較貸借対照表」、期間の下に前期の期間（貸借対照表は前期末・期首の日付）。スマホでは増減率の列を隠して増減額の下に小さく書き、金額の列は金額の幅に合わせる（桁の多い金額は横にスクロール）
- 印刷（`compareStatementDoc`）：決算書の体裁で、A4縦は幅 186mm（科目｜31mm×3｜19mm）。期間の2行目（`period2`）に前期の期間を書き、その分だけ表を下げる。資産合計（二重線）の次の部の見出しの前は1行空ける

## 決算報告書の表紙（v0.61.0）

市販の会計ソフトの決算報告書の表紙（[弥生会計 決算書](https://support.yayoi-kk.co.jp/product/account/kessansho_c.html) の構成）にならい、決算書（法人）を1冊にする印刷の最初に表紙を付けられるようにした。

- 書くこと：期数（第○期）・表題（決算報告書）・期間（自・至の2行、左をそろえて中央）・会社名・所在地
- 期数は設定に持たないため、印刷条件の欄で入れる（1〜999 の整数。空欄なら書かない）。所在地は請求書の設定の住所があるときだけ選べる
- 表紙は表題・会社名・単位の見出しとページ番号を書かず、ページ番号を数えない（次のページを「- 1 -」とする）。印刷の組版（`print-layout.js`）の `{ type: 'cover' }` の部品
- 文字の大きさと位置（用紙の高さに対する割合）は、市販の表紙の見た目に合わせて決めた（推測を含む）

## 未対応・今後

- 表紙の期数は覚えておかない（印刷のたびに入れる）。会社の設立日などから自動で出すには、設定に項目を足す必要がある
- 前期と比べる表は、製造原価報告書・販売費及び一般管理費内訳書には無い
- 青色申告決算書・収支内訳書の印刷（申告書の様式）は、v0.57.0 の様式のまま
