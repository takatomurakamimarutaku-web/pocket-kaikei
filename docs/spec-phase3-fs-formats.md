# 決算書の勘定式・個別注記表のパターン・帳票の期間（年・月・日）・摘要と科目の検索（v0.68.0）

たかとさんの依頼（2026-10-30）：「決算書系（貸借対照表、損益計算書、製造原価報告など）は勘定式と報告式を選択できるようにして。注記表は何パターンか作れるようにしよう。帳票は期間（年、月、日）を自由に範囲してできるようにして。摘要検索機能、科目検索機能などをつけよう。」
（同じ依頼の「固定資産台帳のブラッシュアップ」は別の作業で進める）

## 1. 決算書の勘定式と報告式

| 帳票 | 報告式 | 勘定式 | 初めの様式 |
| --- | --- | --- | --- |
| 貸借対照表 | 資産の部・負債の部・純資産の部を上から（v0.53.0〜） | 左に資産の部、右に負債・純資産の部（v0.53.0〜） | 勘定式 |
| 損益計算書 | 売上高から当期純利益まで上から、段階利益あり | 左（借方）に費用と当期純利益金額、右（貸方）に収益 | 報告式 |
| 製造原価報告書 | 材料費・労務費・製造経費 → 当期総製造費用 → 仕掛品 → 当期製品製造原価 | 左に材料費・労務費・製造経費・期首仕掛品棚卸高、右に期末仕掛品棚卸高・当期製品製造原価 | 報告式 |

- 画面：損益計算書・貸借対照表・製造原価報告書・決算書（計算書類）の各帳票に「様式 報告式｜勘定式」の切替。選んだ様式はアプリを開いている間だけ覚える（帳簿のデータではないので保存しない。金額の単位と同じ）
- 印刷：印刷条件の「様式」。初めは画面で選んだ様式。決算書を1冊にするときは、貸借対照表・損益計算書・製造原価報告書ごとに選べる
- 前期と比べる表（比較損益計算書・比較貸借対照表）は様式が決まっているので、切替を隠す

### 勘定式の損益計算書の行（`js/fs-rows.js` の `incomeStatementAccountRows`）

- 区分の向き（`GROUPS` の `side`）で左右に分ける。費用（借方の区分）は左、収益（貸方の区分）は右
- 区分の合計は区分の見出しの行（貸借対照表の勘定式と同じ）。売上原価・材料費の期末の棚卸高は報告式と同じく区分の中で「合計」の後に差し引く（正の数で書く）
- 段階利益（売上総利益など）は書かない。最後の行だけ：
  - 法人：当期純利益なら左に「当期純利益金額」、当期純損失なら右に「当期純損失金額」（零から差し引いた正の数。会社計算規則 第94条の表示）
  - 個人：左に「青色申告特別控除前の所得金額」（赤字なら△のまま左。青色申告決算書の所得金額の欄と同じ）
  - 製造原価報告書：右に「当期製品製造原価」
- 左右の合計は必ず一致する（費用＋利益＝収益）。テスト `test/fs-formats.test.js` で確かめている
- 公開資料に勘定式の損益計算書の細かな配置の仕様は無いため、簿記の損益勘定の形（借方｜貸方）と、このアプリの勘定式の貸借対照表の配置に合わせた（推測を含む）

## 2. 個別注記表のパターン

会計監査人を置かない株式会社が対象。パターンは「会社の区分」「冒頭に書く会計のルール」「該当の無い項目の書き方」の組み合わせで、期間に保存し（`period.statementNotes`）、注記を保存していない次の期間は前期の注記からパターン・会計方針・株式の数を引き継ぐ（保存するまでは仮の内容）。

### 会社の区分と表示する項目（会社計算規則 第98条）

第1項の項目：一 継続企業の前提、二 重要な会計方針、三 会計方針の変更、四 表示方法の変更、四の二 会計上の見積り、五 会計上の見積りの変更、六 誤謬の訂正、七 貸借対照表等、八 損益計算書、九 株主資本等変動計算書、十 税効果会計、十一 リースにより使用する固定資産、十二 金融商品、十三 賃貸等不動産、十四 持分法損益等、十五 関連当事者との取引、十六 一株当たり情報、十七 重要な後発事象、十八 連結配当規制適用会社、十八の二 収益認識、十九 その他。

第2項で表示しなくてよい項目：

- 第1号（会計監査人設置会社以外の株式会社〔公開会社を除く〕）：一・四の二・五・七・八・十〜十八 → **非公開会社**のパターン：重要な会計方針・会計方針の変更・表示方法の変更・誤謬の訂正・株主資本等変動計算書・収益認識・その他
- 第2号（会計監査人設置会社以外の公開会社）：一・四の二・五・十四・十八 → **公開会社**のパターン：上に加えて 貸借対照表等・損益計算書・税効果会計・リース・金融商品・賃貸等不動産・関連当事者との取引・一株当たり情報・重要な後発事象

出典：令和2年8月12日法務省令第45号による改正後の会社計算規則 第98条（[新日本法規 改正条文](https://www.sn-hoki.co.jp/data/pickup_hourei/onct/KAISYAKEISANNKISOKU-REI20200812-45.html)。e-Gov 法令検索の原文は未照合）、項目の区分の一覧は [弥生 個別注記表とは](https://www.yayoi-kk.co.jp/kaikei/oyakudachi/notes-non-consolidated/) でも確認。

- 「収益認識に関する注記」は「収益認識に関する会計基準」で収益を計上している会社が書く（中小会計要領の会社は通常書かない）。入力したときだけ出す
- 「貸借対照表等に関する注記」は、非公開会社でも「有形固定資産の減価償却累計額を注記する」（任意）を選んでいれば出す（今までと同じ）
- 一株当たり情報（公開会社）：文を入れなければ、期末の発行済株式の数から自己株式の数を引いた株式数で、純資産合計と当期純利益を割る（期中に株式の数が変わらない前提。小数第3位を四捨五入して円・銭で書く）。期中に変わったときは文を入れる

### 冒頭に書く会計のルール

- 中小会計要領：「この計算書類は、「中小企業の会計に関する基本要領」によって作成しています。」
- 中小会計指針：「この計算書類は、「中小企業の会計に関する指針」によって作成しています。」
- 書かない（初め）

出典：実務の記載例（[鮎沢パートナーズ 決算書の注記の作成](https://ayusawa-partners.jp/column/kessansho-chuuki-sakusei)、[弥生 個別注記表とは](https://www.yayoi-kk.co.jp/kaikei/oyakudachi/notes-non-consolidated/)）。中小会計要領・中小会計指針の本文は未照合。

### 該当の無い項目の書き方

- 初め：該当が無い項目は出さない（今までと同じ）
- 「該当事項はありません。」と書く：表示する項目（パターンの項目）で入力の無いものも見出しを出して「該当事項はありません。」

### 入力の欄（`DEFAULT_NOTES`）

前の版の欄に、`companyType`・`standard`・`showNone`・`securities`（有価証券の評価基準及び評価方法）・`revenue`（収益及び費用の計上基準）・`balanceSheetNotes`・`incomeStatementNotes`・`taxEffect`・`lease`・`financialInstruments`・`rentalProperty`・`relatedParty`・`perShare`・`subsequentEvents`・`revenueRecognition` を足した。保存は今までどおり `saveStatementNotes`（期間のレコードの中なので DB の版は変えない。前の版で保存した注記は、足した欄を初期値で補う＝非公開会社・冒頭の文なし）。

## 3. 帳票の期間（年・月・日）

共通部品 `monthRangePicker`（`js/views/report-common.js`）を、月だけでなく日まで選べるようにした。

- 選択肢：期間全体／各月／四半期（第1〜第4）／半期（上半期・下半期）／月で指定（開始月〜終了月）／日付で指定（開始日〜終了日）
- 四半期・半期は会計期間の最初の月から3か月・6か月ずつ数える（月次推移試算表の四半期計・半期計と同じ）。期間が6か月以下なら半期、3か月以下なら四半期は出さない
- URL の from・to：月の区切りなら今までと同じ `YYYY-MM`、日で選んだときは `YYYY-MM-DD`。期間の外は期間の初日・末日に寄せ、前後が逆なら入れ替える（`js/period.js` の `parseRange`）
- 列が月の帳票（月次推移試算表・予算と実績）は `monthsOnly` で月の単位だけ
- 印刷条件の期間は「開始日・終了日」の日付の欄（印刷プレビューに `type: 'date'` を足した）。初めは画面で選んだ範囲

| 帳票 | 期間 |
| --- | --- |
| 残高試算表・総勘定元帳・補助元帳・消費税集計・部門別損益・摘要と科目の検索 | 年・月・日 |
| 損益計算書・製造原価報告書（期間の合計） | 年・月・日（損益の科目は範囲の中の発生額。`rangeRows`） |
| 貸借対照表 | 時点：期末・各月末・日付（`asOfPicker`。当期純利益は期首からその日までの累計を繰越利益剰余金に含める） |
| 仕訳帳・現金出納帳（印刷） | 印刷条件の開始日・終了日 |
| 月次推移試算表・予算と実績 | 月の単位 |

- 損益計算書を期間の途中で見て「前期と比べる」ときは、前期の同じ月・日の範囲（当期の初日から何か月目かで当てはめる）と比べる
- 繰越の行の名前：期首からなら「前期繰越」、月の初日からなら「前月繰越」、月の途中の日からなら「前日繰越」

## 4. 摘要と科目の検索

### 摘要・科目の検索の画面（帳票 › 帳簿 › 摘要・科目の検索、`#/reports/search`）

- **摘要で探す**：摘要・補助科目（取引先など）・部門の名前・金額で、仕訳の明細（行）を探す。空白で区切ると、すべての語を含む明細だけ。語が数字だけ（カンマ・円は無視）なら金額が同じ明細も。ひらがな・カタカナ、全角・半角、大文字・小文字は同じとみなす（`normalize`）
  - 科目で絞り込める（仕訳の入力と同じ科目の選ぶ画面）・期間（年・月・日）
  - 表示：明細（日付・伝票No｜科目／相手科目・摘要｜借方｜貸方、合計）、摘要ごとにまとめる（同じ摘要の件数・借方合計・貸方合計・使った科目・最後の日付。件数の多い順）
  - CSV に書き出せる（日付・伝票No・科目・補助科目・相手科目・借方・貸方・摘要）。画面は最初の300件まで
- **科目で探す**：コードの前方一致・科目名・区分の名前（流動資産など）の部分一致。科目名の前方一致・コードの一致を先に並べる。期間の終わりの残高と件数を出し、押すと総勘定元帳（その期間）、補助科目があれば補助元帳へ

### 総勘定元帳

- 科目を探して選ぶボタン（コード・科目名）
- 摘要で絞り込む欄：摘要・相手科目に語をすべて含む明細（語が数字だけなら金額が同じ明細も）。残高は絞り込む前の残高のまま、月計は出さない。絞り込んだ件数・借方・貸方の合計を出す

仕訳帳の検索（摘要・科目・金額、詳しい検索）は今までどおり。
