# 優良な電子帳簿への対応と青色申告特別控除の年分ごとの選択肢（v0.26.0）

## 目的

令和9年分以後、個人の青色申告特別控除は「複式簿記＋e-Tax＋優良な電子帳簿」で75万円になる。
Pocket会計で作る仕訳帳・総勘定元帳が優良な電子帳簿の機能要件を満たすように、訂正・削除の履歴、
組合せ検索、帳簿間の相互関連性を加え、要件ごとの対応と利用者がすることを画面で説明する。

## 実装

### 訂正・削除の履歴（規則5⑤一イ）

- IndexedDB に `journalHistory` ストアを追加（`DB_VERSION` 3、`journalId`・`periodId` の索引）
- Repository の仕訳の保存・削除・削除の取消（`putJournal`・`deleteJournal`・`restoreJournal`・`undoDisposal`）が、
  同じトランザクションで履歴を書く。仕訳を書き込むトランザクションには自動で `journalHistory` を加える
  - 登録（create）・訂正（update）・削除（delete）・削除の取消（restore）
  - 変更前・変更後の仕訳をそのまま持つ。日付・行・source が同じ保存は残さない
- 履歴を変更・削除する操作は作らない。バックアップ（`BACKUP_VERSION` 3）に含め、復元では置き換わる
- 一問一答 問27 の「1週間以内の訂正は履歴を残さなくてよい」は使わず、すべての訂正を残す（安全側）
- 画面：仕訳帳 →「訂正・削除の履歴」（`#/journals/history`）。種類で絞り込み、CSV で書き出せる。
  仕訳の編集画面の下にも「この仕訳の履歴」を出す

### 通常の業務処理期間を過ぎた入力（規則5⑤一イ）

- 登録の履歴の日時が、取引日から2か月（`LATE_INPUT_MONTHS`）を過ぎていれば「取引日から2か月を過ぎた入力」と表示する
- v0.26.0 より前の仕訳には登録の履歴がない（`createdAt` は残っている）

### 帳簿間の相互関連性（規則5⑤一ロ）

- 総勘定元帳・補助元帳の各行に伝票No.を表示する（日付のリンクから元の仕訳を開ける）。CSV には変わらない入力No.も出す（v0.44.0。docs/spec-phase2-voucher-subledger.md）

### 検索（規則5⑤一ハ）

- 仕訳帳の「詳しく検索」：日付の範囲、金額の範囲（借方合計かいずれかの行の金額）、取引先（補助科目・摘要）、科目。
  すべての条件を満たす仕訳を会計期間の全体から探す（`searchJournals`）

### 青色申告特別控除の選択肢

- `blueDeductionOptions(year)`：令和8年分まで 65万・55万・10万・0、令和9年分以後 75万・65万・10万・0
- 保存した控除額がその年分に無いとき（令和9年分の55万円など）は65万円で計算し、画面で選び直すよう知らせる（`blueDeductionFor`）
- 所得税の確定申告書の画面も同じ規則で控除額を決める

### 電子帳簿保存の説明ページ（`#/e-book`、その他メニュー）

- 要件ごとに「Pocket会計の機能」と「あなたがすること」を表示（`EBOOK_REQUIREMENTS`）
- 事務手続の書類のひな形（`ebookProcedureText`）を表示し、テキストで書き出し・コピーできる
- JIIMA の認証を受けていないこと、データが端末の中だけにあるのでバックアップが必要なことを明記する

## 未確認の事項
