# 製造原価報告書（法人）

v0.16.0。たかと決定（2026-10-29）：法人だけで作る。

## 使い方

- 事業者の設定で「製造原価」を「使う」にすると、次の科目を追加する（`accounts.js` の `MANUFACTURING`。使っていなければ削除できる。「使わない」に戻しても科目は残す）
  - 在庫（流動資産）：142 製品、143 仕掛品、144 原材料
  - 売上原価：513 期首製品棚卸高、518 期末製品棚卸高（評価勘定）
  - 材料費（`mfg_materials`）：800 期首材料棚卸高、801 材料仕入高、809 期末材料棚卸高（評価勘定）
  - 労務費（`mfg_labor`）：810 賃金ほか
  - 製造経費（`mfg_overhead`）：820 外注加工費、821 電力費、825 減価償却費（製造）ほか
  - 仕掛品棚卸高（`mfg_wip`）：850 期首仕掛品棚卸高、859 期末仕掛品棚卸高（評価勘定）
- コードが使われていれば空いている次の番号にする。科目の判定は目印（hint）で行う

## 計算（`statements.js` の `manufacturingReport`）

- 材料費＝期首材料棚卸高＋材料仕入高−期末材料棚卸高
- 当期総製造費用＝材料費＋労務費＋製造経費
- 当期製品製造原価＝当期総製造費用＋期首仕掛品棚卸高−期末仕掛品棚卸高
- 損益計算書の売上原価に「当期製品製造原価」の行を入れる（期末の棚卸高の行の前）。製造原価の科目がなければ入れない
- 他勘定振替高は扱わない（必要なら振替仕訳で科目を移す）

出典
- 財務諸表等規則 第75条第2項、同ガイドライン75-2の1（製造原価明細書：材料費・労務費・経費、期首仕掛品を加え期末仕掛品を控除）
  参考 https://www.zeiken.co.jp/keieizaimu/article/no3625/ZA00036251901.php
- 国税庁「勘定科目内訳明細書の提出について」の原価の内訳書（材料費＝期首材料棚卸高＋材料仕入高−期末材料棚卸高、労務費、外注費、経費、期末仕掛品棚卸高）
  https://www.nta.go.jp/taxes/tetsuzuki/shinsei/shinkoku/hojin/sanko/02-01.pdf

## 関連

- 決算・繰越の期末棚卸：商品・原材料・仕掛品・製品の棚卸高をまとめて1つの決算整理仕訳にする（`closing.js` の `inventorySets` / `inventoryJournalLines`）
- 固定資産：資産ごとに「償却費の科目」（`expenseAccountId`）を選べる。工場の機械は減価償却費（製造）にすると製造経費に入る
- かんたん入力：仕入に材料仕入高、経費に労務費・製造経費の科目が出る
- 帳票：製造原価報告書（期間の合計／月次推移、CSV、印刷）。帳票メニューには「使う」にした法人だけ出す
