# 第2弾（1）かんたん取引入力・出納帳 仕様

第1弾の振替伝票入力に加えて、簿記の知識が少なくても日々の取引を記録できる入口を作る。
作られるデータは第1弾と同じ「仕訳」だけで、新しいストアは追加しない（DB_VERSION・BACKUP_VERSION は変えない）。

## 1. 入力の入口（＋タブ）

＋タブを押すと「入力メニュー」（`#/entry`）を開く。

| 項目 | 内容 |
|---|---|
| かんたん入力 | 取引の種類を選び、日付・金額・科目・摘要だけで仕訳を作る |
| 振替伝票で入力 | 第1弾の画面（`#/journal/new`）。複合仕訳・税区分の細かい指定はこちら |
| 現金出納帳・預金出納帳 | 口座ごとの入出金と残高（`#/cashbook`） |

## 2. かんたん入力（`#/quick/:kind`）

### 取引の種類

| 種類 | 借方 | 貸方 | 対象 |
|---|---|---|---|
| 売上 | 現金・預金・売掛金 | 売上の科目（区分：売上高・営業外収益） | 共通 |
| 経費の支払 | 経費の科目（区分：販管費・営業外費用） | 現金・預金・未払金・事業主借／役員借入金 | 共通 |
| 仕入 | 仕入の科目（区分：売上原価。棚卸高を除く） | 現金・預金・買掛金 | 共通 |
| 売掛金の入金 | 現金・預金 | 売掛金 | 共通 |
| 買掛金・未払金の支払 | 買掛金・未払金 | 現金・預金 | 共通 |
| 預金の預け入れ・引き出し | 現金・預金 | 現金・預金 | 共通 |
| 生活費などの支払（事業主貸） | 事業主貸 | 現金・預金 | 個人 |
| 自己資金の入金（事業主借） | 現金・預金 | 事業主借 | 個人 |
| 役員からの借入 | 現金・預金 | 役員借入金 | 法人 |

出納帳から開く「入金」「出金」は、口座を固定し、相手の科目をすべての科目から選ぶ。

### 画面

- 日付・金額・借方/貸方の科目・補助科目・税区分（売上・経費・仕入の損益側だけ表示）・摘要
- 候補が8件以下の科目はボタンで並べ、それより多いときは科目選択シートで選ぶ。どちらも「その他の科目」から全科目を選べる
- 保存前に、作られる仕訳（借方・貸方・金額・税区分）をプレビューで表示する
- 前回その種類で選んだ科目を初期値にする（端末内の meta `quickLast` に保存）
- 摘要の候補を選ぶと、その摘要の直近の仕訳が借方1行・貸方1行なら科目も補う
- 登録後は日付を残して続けて入力できる。編集は仕訳帳・出納帳から振替伝票の画面で行う

### 検証

- 金額は `parseYen()` で整数化（1円以上）。借方と貸方に同じ科目（補助科目を含む）は使えない
- 作った仕訳は第1弾と同じ `validateJournal()` と Repository の再検証を通す

### 科目の決め方（名前で判定しない）

- 現金・預金・事業主貸・事業主借は既存の役割（`role`）で選ぶ
- 売掛金・買掛金・未払金・売上高・仕入高・役員借入金には、ロックしない目印 `hint` を付ける
  （`role` と違い、区分の変更・無効化を妨げない。初期値の候補を探すだけに使う）
- 既存のデータ・バックアップから復元したデータには、テンプレートの科目（`template: true`）に
  コードで `hint` を補う（起動時と復元時。既に `hint` があれば変えない）
- 目印の科目が見つからない（無効にした・コードを変えた）ときは、初期値を空にして利用者に選んでもらう

## 3. 出納帳（`#/cashbook?account=&sub=&month=`）

- 対象：役割が現金・預金の科目（補助科目ごとにも見られる）
- 月ごとに、前月繰越・日付・相手科目・摘要・入金・出金・残高を表示（総勘定元帳 `generalLedger()` を使う）
- 「入金を記録」「出金を記録」でかんたん入力（口座固定）を開く
- 行をタップすると振替伝票の編集画面を開く
- 現金の残高がマイナスになる日があれば注意を表示する（記帳漏れ・日付の誤りの可能性）
