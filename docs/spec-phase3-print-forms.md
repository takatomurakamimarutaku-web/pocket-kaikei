# 帳票の印刷様式（PDF プレビュー・印刷）

v0.9.0 の印刷（`docs/spec-phase2-print.md`）は、画面をブラウザの印刷（`window.print()`）でそのまま紙に流すものだった。
v0.53.0 で、帳票を会計ソフトの帳票と同じ考え方の **印刷専用の様式** に組み、アプリ内でプレビューして PDF を保存・共有・印刷できるようにした。

## なぜ作り直したか

- iPhone の「ホーム画面に追加」で開いたアプリでは、iOS が `window.print()` を無視し、印刷画面が開かない（二次情報：[Apple Developer Forums](https://developer.apple.com/forums/thread/22911)、同じ問題への対処の例 [1](https://github.com/sebastianzillessen/experiments/pull/135) [2](https://github.com/CTVMundoVulca/VT-CTV/pull/41)。実機では未確認）。
  そのため、主な使い方（ホーム画面のアプリ）では印刷もプレビューもできなかった。
- 画面の表をそのまま流すため、繰越行・ページ番号・ページごとの見出しが無く、帳票として渡せる形ではなかった。

## 仕組み

外部ライブラリなし・ビルド不要の方針のまま、次の3つを自作した。

| ファイル | 役割 |
|---|---|
| `js/print-layout.js` | 組版（純粋関数）。帳票の内容（見出し・表・文）を A4 のページに割り付け、文字・罫線・塗りの部品（mm）にする |
| `js/print-pdf.js` | PDF 書き出し（純粋関数）。部品を PDF 1.4 にする |
| `js/views/print-preview.js` | プレビュー。同じ部品を SVG で描き、「PDF」「印刷」ボタンを出す |
| `js/print-forms.js` | 帳票ごとの様式（純粋関数）。仕訳日記帳・元帳・出納帳・残高試算表・決算書 |
| `js/print-capture.js` | 専用の様式が無い帳票は、画面の表（thead・tbody・tfoot と class）から同じ様式を作る |

- プレビューと PDF は同じ部品から描くので、改ページ・繰越行の位置が一致する。SVG の文字は `textLength` で PDF と同じ幅にそろえる。
- 日本語フォントは埋め込まず、PDF 標準の日本語フォント（平成角ゴシック W5、Adobe-Japan1、`UniJIS-UCS2-HW-H`）を指定する。表示側（iPhone・Mac・Chrome・Acrobat など）が手元の日本語フォントで描く。
  半角は全角の半分の幅（W で指定）。桁区切りのカンマは前後を詰めて 0.3em にする。半角の空白は字形を描かずに送る（フォントによって四角になるため）。
- ㉑〜㊿の丸数字は Adobe-Japan1-2 と代わりのフォントに無いことがあるので、印刷では (21) のように書く。
- 「PDF」：共有シート（iPhone）またはダウンロードで PDF を渡す。共有シートの「プリント」で AirPrint 印刷、「ファイルに保存」で保存できる。
- 「印刷」：ブラウザの印刷が使える環境（PC・iPhone の Safari）はプレビューの用紙だけを印刷する（`body.printing-preview`、用紙の余白0で A4 の SVG をそのまま）。iPhone・iPad のホーム画面のアプリでは PDF の共有シートを開く（`install.js` の `browserPrintWorks`）。
- 請求書・給与明細・源泉徴収票は画面そのものが用紙の形なので、これまでどおりブラウザの印刷（ルートの `print: 'browser'`）。

## 様式（共通）

市販ソフトの帳票（弥生会計の印字サンプル・帳票一覧、勘定奉行の帳票の説明）を参考にした。弥生会計は「すべてプレビュー表示可能で汎用用紙（白紙）にも印刷」できる（[弥生会計 帳票一覧](https://www.yayoi-kk.co.jp/products/account/function/print.html)）。公開資料に用紙の寸法などの細かな仕様は無いため、配置は一般的な会計帳簿の書き方に合わせた（推測を含む）。

- 用紙：A4。縦が基本で、縦に収まらない表（月次推移など列の多い表）は自動で横。改ページの区切り（科目・決算書の各表）ごとに向きを決める
- 余白：左右 12mm、上下 11mm
- 各ページの上：中央に表題（15pt・二重下線）と期間（「自 令和8年4月1日　至 令和9年3月31日」）、左に事業者名、右に作成日（和暦）、表の右上に「（単位：円）」
- 各ページの下：中央にページ番号「n / N」、右に「Pocket会計」
- 表：見出し行は灰色の地で各ページに繰り返す。外枠 0.3mm、縦の罫線 0.1mm。合計行は二重線、小計行は上に線。区分の見出しの行は薄い地で、次の行と同じページに置く
- 文字：表は 8pt。列に収まらない文字は横に縮め（60% まで）、それでも収まらなければ末尾を「…」
- マイナスは △

## 帳票ごとの様式

| 帳票 | 様式 |
|---|---|
| 仕訳日記帳（仕訳帳） | 日付・伝票No.・借方（科目／補助科目・部門、税区分、金額）・貸方（同）・摘要。複合仕訳は行に分け、1件の仕訳はページをまたがない。仕訳の区切りは太線。ページの変わり目に「次頁へ繰越」「前頁より繰越」（借方・貸方の累計）。最後に合計 |
| 総勘定元帳・補助元帳 | 科目ごとに改ページし、ページの左上に「[コード] 科目名（借方残／貸方残）」。日付・伝票No.・相手勘定科目／相手補助科目・摘要・税区分・借方・貸方・残高。前期繰越（途中の月からなら前月繰越）、2か月以上なら月計、最後に合計。ページの変わり目に繰越行（借方・貸方の累計と残高） |
| 現金出納帳・預金出納帳 | 元帳と同じ様式で、借方・貸方を入金・出金と書く |
| 残高試算表 | 貸借対照表の科目と損益計算書の科目に分け、【区分】の見出し・科目・区分の計・資産合計／負債合計／純資産合計。列は繰越残高・借方・貸方・残高・構成比（貸借対照表は資産合計、損益計算書は売上高に対する割合） |
| 損益計算書・貸借対照表 | 報告式。科目の金額は左の列、区分の計と段階利益は右の列。貸借対照表の期間は「令和9年3月31日 現在」。前期と比べる表は画面の表から |
| そのほか（月次推移・消費税・決算書・内訳書・申告書類・固定資産台帳など） | 画面の表から作る（`print-capture.js`）。表の caption・見出しは見出しに、tfoot と `total` の行は合計行、`group`・`heading` の行は区分の見出しにする。青色申告決算書は4ページをページごとに改ページ |

## 確認状況

- 実施：`npm test`（`test/print.test.js`：文字の幅と縮小、和暦、列の幅、横向きの判定、繰越行の金額、keep、PDF の構造と xref、各帳票の様式の金額）。
  `scripts/print-shots.cjs` で法人・個人のサンプルの16帳票のプレビューを開き、PDF を保存した。PDF は poppler（pdftoppm）で画像にして目で確認し、pdf.js（pdfjs-dist 4.10）で日本語の文字が読めることを確認。
  Chromium の印刷（`page.pdf`）で、プレビューの用紙が1枚ずつ A4 に印刷されること（縦・横）を確認。
- 未確認：iPhone 実機（ホーム画面のアプリ・Safari）での共有シート・AirPrint・「ファイルに保存」、iOS・macOS のプレビューでの日本語フォントの表示（埋め込まない日本語フォントの置き換え）、Acrobat Reader・Windows の Edge での表示、Windows 版（exe）での保存。
