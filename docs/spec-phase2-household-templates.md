# 家事按分と定型仕訳・毎月の繰り返し仕訳（v0.27.0）

## 家事按分（個人）

- 経費の科目（減価償却費を除く）に事業割合（`businessRatio`、1〜99 の整数 %）を持たせる。未設定は null
  - 科目の編集画面と、決算・繰越の「3. 家事按分」で設定する（`Repository.saveBusinessRatios` でまとめて検証・保存）
- 決算・繰越の「3. 家事按分」で、期間の経費を事業割合で分け、家事の分を事業主貸へ振り替える仕訳を期末日で登録する
  - 仕訳：借方 事業主貸（家事の分の合計）／貸方 各経費（科目・補助科目・税区分ごと）。`source: 'household'`、`adjusting: true`
  - 按分の元：科目・補助科目・税区分ごとの借方−貸方（家事按分の仕訳と減価償却の仕訳は除く）
  - 事業の分は1円未満を切り捨て（家事の分＝元の額−事業の分）
  - 減価償却費は固定資産台帳の事業専用割合で按分済みなので対象外
- 消費税：家事の分の行は元の行と同じ税区分を付けて貸方にし、課税仕入れから差し引く。税区分のチェックでは警告しない
- 登録済みなら一覧へのリンクを出す。経費を直したら仕訳を削除して登録し直す（棚卸・減価償却と同じ）

出典
- 国税庁 タックスアンサー No.2210（家事関連費のうち必要経費になるのは、業務の遂行上直接必要であったことが明らかに区分できる金額）
  https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2210.htm
- 消費税法基本通達 11-1-4（家事消費・家事使用の部分は課税仕入れに当たらない。使用率・使用面積など合理的な基準で按分）
  https://www.nta.go.jp/law/tsutatsu/kihon/shohi/11/01.htm

## 定型仕訳・毎月の繰り返し仕訳

- IndexedDB に `templates` ストアを追加（`DB_VERSION` 4）。バックアップにも含める（`BACKUP_VERSION` 4、v3 からは空で変換）
- レコード：`{ id, name, lines, repeatDay, createdAt, updatedAt }`。`repeatDay` は 1〜31（31 は月末）か null
- 登録・編集：振替伝票と同じ画面（`#/template/new`・`#/template/:id`）。日付の代わりに名前と「毎月作る」日を入れる
  - 金額を空欄（0）にすると、呼び出したときに入力する。毎月作るものは全行の金額が要り、貸借一致が必要
  - 仕訳の編集画面の「定型仕訳に登録」から、その仕訳の内容で作れる
- 使う：定型仕訳の画面の「使う」で振替伝票に呼び出す（`#/journal/new?template=`）
- 毎月の仕訳を作る：月を選ぶと、毎月作る定型仕訳とその月の日付を一覧にし、選んだものをまとめて登録する（`saveJournals`）
  - 作った仕訳は `source: 'template'`・`sourceId`（定型仕訳の id）を持ち、その月に作成済みかの判定に使う
  - 月末を超える日（2月の30日など）は月末日にする
- 定型仕訳で使っている科目・補助科目は削除できない。定型仕訳を削除すると tombstone を残す
